    使用说明

    导入与评估

    输入 ID 或上传 _m.bytes 文件，点击“评估模板”后进入独立结果界面。进度显示整批已处理数量，全部处理后才满格。返回导入不会丢弃本批结果；“重新开始”会清空当前入口和结果。读取失败单独列出，不当作没有问题。

    两种全遮盖

    邻层一压一：非塔牌 X、Y 完全相同，层号相差 1。悬空全遮盖：同 XY、相隔至少两层，且中间没有任何 Tile 与下牌的 2×2 牌面发生正面积压盖；四分之一、二分之一或全部压盖都排除，只有边缘相接不排除。中间全是空层也算，例如第16、19层；真实层号不压缩。多层同 XY 按实际相邻层序配对，不越过中间牌重复计数。

    正常塔牌不作为命中对象，按实际展开位置参与中间遮挡检测；包括所有普通牌型，不限 A/B。几何命中不代表关卡不可解。

    查看、定位和人工编辑

    点击“查看／编辑”，左侧是改前模板，右侧是当前新模板，两边同一比例、同步切层。“定位全遮盖（数量）”循环定位红框问题牌；“定位悬空（数量）”独立循环定位蓝框无下层承接牌，查看和编辑状态都能使用，不必先保存。自动跳层、滚动并聚焦对应牌，提示区区分原、新模板；同一张牌兼有两类问题时同时标示。数量不成组等无单张坐标的提示不捏造落点；不检查、不标记所谓坐标安全范围。底部全遮盖坐标入口保留，鼠标方形锚点显示准确落点。

    层级栏与塔占比工具一致：无限制、减一层、滑条、加一层、仅看当前层。指定层只增删该层；“无限制”显示全部层、不能单层查看，新增自动落层、删除实际点中的牌。“删除本层以上”不含本层，也包含未显示的更高层；批量删除先确认张数，进入草稿且可撤回。

    下一行提供四向平移、复位、顺/逆时针90°旋转、A/B笔刷与补到3的倍数还差的数量、删除复选、撤回及按坐标增删。最右按钮显示“去编辑”；进入后无修改为“退出编辑”，有修改为“保存编辑”。非编辑平移旋转自动保存，仍可撤回；编辑中变换和增删留在草稿。塔的坐标和方向随整体变换同步。

    左键加牌、右键删牌。人工编辑过程中可自由增删。保存和导出时，总牌数及 A/B 各自的数量须为 3 的倍数（含塔牌），未成组时保留草稿并提示还需补删的数量；这是硬性限制。全遮盖、悬空和同层重叠仅提示，不影响保存导出；原模板已有这些摆放问题也不用先修好。仅损坏文件、无法写入格式的数值、过期修订等技术问题会保留草稿并要求处理，避免丢数据或覆盖其他修改。关闭未保存修改时可继续编辑、关闭不保存或保存后关闭。当前服务会话内可撤回已保存操作，重新打开或刷新也可恢复；服务重启需重新导入。

    一键修复

    以尽量保持原关卡体验为目标，按顺序尝试：普通隐藏空位等量补回、移动少量内部隐藏牌、少量调整总数，最后才补入已有塔。默认先删上方问题牌，也尝试下方或中间问题牌；删除与补承接作为完整方案核验，不因中间临时悬空直接放弃。原非塔表面与外轮廓保持，其余露出牌不动、不被新牌盖住；问题上方牌可由同位置、同类型的原下方牌替代。

    优先保持总数及各牌型数量不变；必要时净增减不超过3张，各牌型数量变化绝对值合计也不超过3张，最终总数及A/B各自仍为3的倍数。其他原普通牌最多改动3张：主要移动完全隐藏的内部牌；若整层都是问题牌，可尝试删除该层并压缩其上层号，涉及的其他普通牌也计入3张限额，且仍保持露出面。其他原有空层不自动压缩。

    塔仅作为最后补位方案，增、删、移动塔牌合计不超过6张，并尽量少改。不新建或清空塔，不改锚点和方向，等高塔仍等高，原有严格高低关系保持，例如5、5、5可变6、6、6；2、4、2可变4、5、4。塔自身外轮廓可随牌量延长，不要求原差值或比例不变，但不能盖住原非塔露出面。

    机器只修复全遮盖，不要求修复原模板已有的普通悬空：原悬空牌身份、类型和位置不变时可保留，蓝框提示不妨碍修复。悬空全遮盖仍是必须修复的全遮盖，不能豁免；机器不新增悬空，普通新增牌藏在已有牌下、紧邻上下层均有承接。不以所谓坐标安全范围限制原牌；其他低扰动、冲突、成组和零全遮盖核验保留。人工保存和导出仅保留牌数成组硬性限制，其余摆放问题只提示。修复后显示问题牌、其他普通牌、塔牌的实际改动数及总量变化；重复修复仍按最初导入模板累计核验，不重新获得改动额度。结构核验不等于线上胜率、时长或道具消耗不变，导出后仍建议复核试玩。

    有限搜索未找到合规方案时保留当前模板并说明原因，不声称已证明无解；同批成功项仍可人工编辑、撤回和导出。搜索提前到达预算但已有合规结果时保留结果，并明确它不代表全局最少改动。

    命名与导出

    先保存修改。未勾选时默认导出全部有修改的新模板，包含机器和人工修改，即使仍有全遮盖或悬空也可导出；未修改项和读取失败项不生成新文件。勾选后只导出选中项；表头只选当前页，“选择全部有修改模板”跨页选择，搜索、筛选和翻页不丢失勾选。可清空选择回到默认全部范围。

    设置批量命名规则，例如 fixed{原模板ID}。重名自动加 v2、v3，文件名与内部 ID 一致。默认导出到本工具工程内“输出模板”文件夹，可修改目录；展开“同步到模板库（可选）”可另外勾选模板仓、Tile编辑器仓，各目录使用同一新文件名。点击“预览导出”查看范围、命名、路径和提示，再“确认写入”；预览本身不写文件。写入显示整批进度和逐目标结果，某目录失败会明确提示，不冒充全部成功。预览后模板被修改或目标出现同名文件时需重新预览，不覆盖已有文件。

    “下载新模板 ZIP”按相同勾选范围直接打包，不写同步目录。写入完成也可下载 ZIP。评估 CSV 与坐标 CSV 导出整批当前结果，不受筛选、勾选和分页影响。

    数据安全

    读取的源模板和关卡配置不修改。上传、编辑和机器修复在本机处理，不传外部服务；确认导出仅创建新文件，可选同步也不提交或推送仓库、不发布线上配置。路径和文件名仍需安全有效。服务重启后需重新导入评估；内存中已保存不等于已写入磁盘，请及时导出或下载新模板。
