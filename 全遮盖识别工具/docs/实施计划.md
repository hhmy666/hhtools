# 全遮盖扫描与识别工具

目标：按用户指定的关卡列表、关卡配置和模板仓库重新扫描，并交付独立批量识别工具。

架构：Python标准库本地HTTP服务、独立模板解码与遮盖引擎、原生HTML/CSS/JS。共享同一识别引擎用于关卡扫描和交互评估，不写入源模板或配置。

约束：根目录仅启动器和工程文件夹；白色/蓝绿色；继承塔占比工具的68px顶栏、188px侧栏、44px控件、30/24/18/14/12px字号与本地字体。原生单选、语义表格、统一进度，错误不能被当成未命中。后续用户已授权相关工具改动定向Git提交推送；仍不修改配置或发布。

## 识别口径

- 候选为非塔牌，StackData锚点内的正常塔牌不作为候选。
- 相邻层：相同XY且Z差1，计一压一全遮盖。
- 隔层：相同XY、Z差至少2，两者之间没有任何Tile正面积压住该2×2牌面。用户最终纠正：四分之一、二分之一及其他正面积压盖均排除，边缘相接不排除；中间全为空层也算命中，例如第16、19层，层号不能压缩。
- 一个坐标多层牌按实际相邻出现顺序报告，不跨过中间牌配对。层号对用户从1开始，保留真实XY。
- 线上范围以用户指定CSV快照为依据：DDAType=1读取DDALevelId1–3，其余读取LevelId；按实际LevelId精确关联TemplateId，不按名称猜测。
- 缺失模板、缺失关卡配置、重复ID冲突、解码失败另列，不能并入无问题。

## 实施任务

1. 引擎与关卡扫描：先写相邻、隔层、部分夹牌、无关夹牌、正常塔排除、DDA分支和缺失项测试；RED后实现；输出命中关卡CSV、模板坐标CSV、异常CSV和来源摘要。
2. 本地服务与启动器：ID批量输入/文件批量上传→异步任务→真实累计进度→分页结果、CSV下载、坐标详情；测试遍历、上传限制、隔离错误、只读与重复提交。
3. 前端：复用原有视觉系统，替换蓝绿色，不增加无关功能；测试状态、筛选分页、导出及桌面/窄屏浏览器交互。
4. 交付核验：独立复算候选几何和CSV映射，检查下载目录文件、根目录结构，迁移旧audit报告至已有研发审阅目录；保留源文件摘要证明未改写。

## 复审重点

四分之一/二分之一/完全夹牌都排除隔层命中，空层不打断；同层重复不伪装成邻层；正常塔不能按普通牌误计；多DDA分支重复引用不重复计同一关卡；文件缺失必须显式保留。
