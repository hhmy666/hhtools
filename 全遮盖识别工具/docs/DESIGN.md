# 全遮盖识别工具｜设计契约

## 使用者与目标
Tile关卡策划批量检查和修复模板。导入、评估修复分属两步页面，支持原/新对比、红框定位、自由编辑、保守机器修复与新模板命名导出。用户指定复用塔占比修改及增加Btile工具的布局和工程架构，不另创视觉方案。

## 视觉与运行时映射
原参照位于 `../../ai减少塔占比/塔占比修改工具/frontend`（从新工具根目录看）。本工具规范→`frontend/assets/styles.css`变量和共享类→`index.html`、`app.js`。
保留68px顶栏、188px侧栏、1560px内容宽、24px卡片内边距、44px控件、10/12/16px圆角。白色表面，蓝绿色主色 #137E85 / hover #0D6269，浅底 #EDF8F8；中性背景 #F6F9F9、文本 #273238、辅助 #617277、边框 #DDE6E7。
唯一字体栈 `"Inter Local", "Source Han Sans SC Local", sans-serif`；复用参照工具的本地字体及许可。只用30/24/18/14/12px五档，数字tabular-nums；控件、代码、坐标继承同一字体。

## 组件与状态
原生button/input/select/textarea、语义table、原生dialog。Select/Listbox接受系统原生弹层，沿用共享字段样式。标题层级h1→h2→h3，不跨级。表格分页20/50/100行、内部横向滚动，搜索可清空；页面自然滚动。一次只评估一个批次，操作中禁用重复开始和重置，真实已处理/总数才增长，整批结束才100%。错误行显式展示，不当作未命中。
窄屏侧栏移底部，表单变单列，操作与长ID可换行，不能造成整页横向溢出。画板严格采用参照工具的18/20坐标系和Tile外观：桌面标签18px、窄屏14px；层号12px、top1px/right3px。窄屏两画板改为单列，不挤压并排。缩略图仅画Tile矩形，不显示标签层号。弹窗局部滚动，标题和关闭按钮常驻可达；打开聚焦关闭按钮，Escape关闭并恢复触发焦点。

## 编辑器一致性修订（2026-11-12）
此前新编辑器的下拉层选择、独立左侧编辑按钮和900px画板上限均属于偏离，不作为新规范。编辑器以旧工具真实preview/manual为准：固定“原模板与新模板对比”标题、1021px级内容区、44px图标及笔刷按钮、两行不换行工具栏、最右动态编辑主按钮。窄屏各工具栏局部横滚，不靠缩小控件隐藏功能；画板仍单列。全遮盖红框与问题定位是本工具业务增量，不代替旧编辑动作。

## 边界
源模板、配置表只读；编辑与自动修复创建服务内存中的新修订，人工保存及导出仅保留总数/A/B各自三张成组硬限制，其他关卡摆放问题不阻拦。全遮盖红框、普通悬空蓝框并独立定位，不标记坐标安全范围。默认全部已修改新模板，可跨页勾选；命名、输出目录及可选两仓同步沿用参照工具。先预览后明确确认写新文件，不覆盖源/已有文件，不自动提交推送或发布。导出与修复使用真实累计进度和逐目标结果，刷新后接回操作；技术格式、来源、修订及路径安全保护保留。机器允许原已有且未改变的悬空，不放过悬空全遮盖，不制造新悬空。自动修复保护非塔俯视轮廓和其余原露出面；普通隐藏补位紧邻上下承接。低扰动修复先普通后塔，其他普通源牌最多改3张，最终牌量净差与逐型绝对差合计≤3，塔源身份/新增成员改动合计≤6，保留锚点、方向、等高及高低关系；塔自身轮廓允许增长。结果列表沿用既有辅助文字、控件和配色，不改变画板及两行编辑工具栏。检测命中不等于关卡不可解，结构通过不证明线上数据相同。
