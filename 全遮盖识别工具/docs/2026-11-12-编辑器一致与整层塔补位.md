# 编辑器一致与整层塔补位 Implementation Plan

> **For agentic workers:** 使用 executing-plans 按各自文件执行，测试先失败再实现。界面与修复引擎两个独立任务可并行；主代理负责接口、集成及浏览器核验。

**Goal:** 全遮盖工具编辑器的布局、控件和操作与塔占比工具一致；自动修复增加整层移除和保留塔形关系的塔内补位。

**Architecture:** 以已有塔占比工具的 template-preview/manual-edit/app.js 工具栏为唯一界面参照，延续独立原生 Web/Python 服务。源文件只读，修订保存与撤回在现有任务内完成；自动修复在内存尝试多个方案，独立核验后才替换。

**Tech Stack:** Python 3.9+、原生 JS/CSS、unittest/node:test、CUA 浏览器。

**Spec:** 用户2026-11-12本条需求及此前明确编辑无约束、保存核验、按层/无限制、撤回、比较、自动修复外形要求。

## Global Constraints

- 不另创编辑界面；完整参照旧工具：层级/无限制/减号/滑条/加号/层号/单层/删除本层/删除本层以上；下一行平移四向/复位/旋转双向/笔刷计数/删除复选/撤回/坐标操作/最右编辑主按钮。各工具栏一行，窄屏局部横向滚动，字号和44px控件不缩小。
- 最右主按钮按状态“去编辑／退出编辑／保存编辑”；非编辑平移旋转自动核验保存，已保存操作可撤回；编辑状态变换与增删入草稿，保存才核验。
- 删除本层以上不含本层；批量删除明确范围和数量，确认且可撤回。指定层仅增删该层；无限制禁止单层查看、自动落层；准确方形锚点与右键删除保留。
- 自动修复默认上方牌；可整层移除仅当该层所有牌都是可删全遮盖上方牌。移除后可尝试压缩该层以上的Z，不压缩其他原有空层；实际几何变化须经表面保护核验。
- 补牌按原类型等量，可在已有中间层隐藏空位，或既有塔内。塔内增加不改锚点、方向、塔顺序；保持等高组等高及严格高低关系（5/5/5→6/6/6，2/4/2→4/5/4可行）。新增塔展开长度是用户本条新增授权，非塔露出牌及非塔轮廓仍保护。不能创建新塔。
- 先删后补阶段禁止造成保留牌的新悬空；普通补位紧邻上下承接；塔牌按既有投影承接验收。最终总量/各类型数量不变，零全遮盖、无同层冲突、无悬空、元数据保留；失败原字节保留、同批隔离。
- 不动源模板或配置，其他脏工作区不混入；相关修改完成后提交推送Git。

## Review Focus

1. 塔的平移旋转必须同时更新StackData且未知字段保留，禁止仅挪TileData造成错分塔。
2. 本层以上排除所选层，含隐藏高层；清空和变换撤回恢复牌、塔及坐标。
3. 非编辑撤回跨重新打开/刷新有效，保存错误保留草稿，旧版本/正在修复导出请求不覆盖结果。
4. 整层删除压缩不能移动塔投影或改变非塔表面而未察觉；原有空层不自动消失。
5. 塔内补位必须满足等量与类型余额、等高组和高低关系；不可把部分成功当作整批成功。
