# 交互契约

| 能力 | 唯一实现 | 约束 |
| --- | --- | --- |
| 导入与任务 | app.js client / covercheck.server | ID或文件二选一；真实累计进度；重复开始锁定；错误后保留输入；只读模板 |
| Select/Listbox | index.html原生select | native系统弹层；中文label、键盘选择、共享CSS |
| 表单 | .field / novalidate / app.js | 文字错误、aria-invalid、关联说明、聚焦错误；路径由用户明确输入 |
| 表格 | view.js分页与筛选 | 20/50/100、结果计数、无匹配、局部滚动、错误不隐去 |
| 反馈 | 页面inline status / progress | 单一进度区，不造ETA、不重复提示，不以满格代表无问题 |
| 弹窗 | 原生dialog / app.js | showModal、焦点恢复、Escape、正文可滚动、关闭常驻 |
| 对比与编辑 | CoverEditor / editor.js + editor.css；参照旧preview/manual编辑器 | 完整两行工具栏：层加减/无限制/滑条/单层/本层及以上删除；平移/复位/双向90°旋转/笔刷计数/删除复选/撤回/坐标；主按钮最右去编辑/退出编辑/保存编辑。草稿操作不限几何，保存才核验；非编辑变换自动保存并支持撤回；塔元数据同步 |
| 已保存撤回 | server rows/undo + revision | 最近50次不同字节修订；任务服务会话内刷新/重开可恢复；版本单调递增，忙锁，撤回后旧ZIP失效，原问题板恢复不冒充可导出修复 |
| 一键问题定位 | CoverEditor problemTargets / data-locate-issue | 有可定位问题即显示，与旧工具相同反馈区和row-action样式，查看/编辑均可用，无需保存报错；按去重坐标计数并循环问题牌，自动切层/红框/滚动/焦点；原、新模板来源明确，安全核验问题不误标为全遮盖，非坐标类数量错误仅提示 |
| 自动修复 | repair_search.py / lowimpact.py / server.py | 普通同数量→内部隐藏重排≤3→数量净差/逐型绝对差合计≤3→塔变化≤6最后兜底；比较上下/中间问题删除，整问题层可压缩但不折叠其他空层；非塔轮廓/表面不变，塔自身轮廓可延长但阵型关系不变；完整方案最终全牌支撑/冲突/零全遮盖核验。初始source累计限额，失败保留当前修订；成功列表显示独立改动数，不承诺线上数据等效或全局最优 |
| 命名与导出 | server export job / delivery.py / app.js | 默认全部已保存有修改项，跨页勾选后仅选中项；新ID与文件名一致、跨目标重名自动版本、不覆盖已有文件；预览不写入、明确确认才写输出目录及可选模板仓/编辑器仓；真实进度及逐目标部分失败可恢复；摆放问题不阻拦交付，成组硬限制保留 |
| 操作恢复 | snapshot.operation | 刷新恢复正在运行的repair/export；最近完成ZIP可重新下载；保存新修订后旧ZIP不冒充新版本 |
| 滚动条 | styles.css全局规则 | 可见、token化、窄屏不隐藏关键信息 |

业务口径以本次用户确认和 docs/实施计划.md 为准；同XY连续Z序对，区分邻层和悬空，排除StackData正常塔。读取失败为error而不是clean。用户提供的两份配置CSV快照定义本次扫描范围，不额外推断线上发布状态。

## 2026-11-12 最新提示式保存约定（取代上表中旧核验约束）

- 依据：本轮用户三张截图及明确要求。人工保存/导出对全遮盖、悬空、同层冲突均只提示；总数及A/B各自三张成组是硬限制，未成组不能保存导出；删除坐标安全范围检查及标记。仅二进制读写、int32格式、来源身份、过期版本与路径/文件名安全仍可拒绝。
- `CoverEditor` 保持两行工具栏/字体/字号；全遮盖红框和“定位全遮盖”、普通悬空蓝框和“定位悬空”独立循环，兼有两类时叠加。查看/编辑均可定位，支持真实塔投影承接。
- 机器终态只豁免最初原模板已有且身份/类型/XYZ不变的悬空；全遮盖包括隔层悬空全遮盖仍须清零，不新增悬空。其余低扰动预算与表面保护不变。
- 恢复到原字节后取消已修改/可导出状态。默认交付范围不受搜索、分页影响；有勾选时用明确勾选范围。CSV仍为整批评估结果，与模板交付范围分开。
- 同步默认不选；输出目录默认工程/输出模板。预览绑定修订与目标目录身份；确认后禁止覆盖，竞争或修改要求重新预览。写入失败按目标说明，ZIP仍可下载；不执行仓库Git或线上发布。
