# 全遮盖识别工具

用户为Tile Family关卡策划，目标是在不改动源模板的前提下，快速批量查找相邻一压一与隔层悬空全遮盖，得到明确坐标和真实层号，并修复后导出新模板。最新授权包含改前改后对比、自由编辑、保守自动修复、批量命名、输出目录写入及可选模板仓/编辑器仓同步；不包含关卡配置写入或线上发布，不自动提交推送这些目标仓库。

权威需求：2026-11-11本对话用户确认。相邻：非塔牌同XY且Z差1。悬空：同XY且Z差>=2，任意中间Tile正面积压住该牌面都排除（包括四分之一、二分之一）；空层不打断。正常StackData塔排除，塔实际投影参与夹牌检查。该结论是几何判定，不推断关卡解法。

桌面优先、本机浏览器、简体中文，严格沿用塔占比修改工具的排版/字号/字体/本地Python+原生Web架构，只更换白色与蓝绿色。参照代码和本次用户截图为视觉依据，无新视觉方向选择。默认模板仓由用户明确指定；所有配置、模板只读。

成功标准：批量ID/文件两入口一致；失败不伪装为干净；真实整批进度；层号含空层不压缩；CSV可复查；一键启动；根目录只保留启动器和工程文件夹。无待定业务问题。

## 当前规则（2026-11-12，1.4.0；优先于下文历史验收记录）

- 人工修改的全遮盖、普通悬空、重叠只提示，不阻止保存或导出。总数及A/B各自三张成组是硬限制（含塔牌），未成组保留草稿、不能保存导出。不检查、不标记坐标安全范围。损坏二进制、不可序列化值、伪造来源、过期版本、路径和文件名安全仍保护数据。
- 全遮盖红框、悬空蓝框，查看/编辑均分别循环定位。两类兼有时叠加提示；实际塔投影参与悬空检查。
- 机器允许最初原模板已有且身份/类型/XYZ保持不变的悬空，无需顺带修复；悬空全遮盖仍必须消除。其余低扰动预算不变，不制造新悬空。
- 默认交付全部有修改且已保存的新模板，勾选后只交付选中项；跨页选择与当前页选择区分。未修改和读取失败项不生成新文件，恢复原字节后不再算新模板。
- 默认工程/输出模板目录，可选同步模板仓及Tile编辑器仓；只读预览绑定修订后明确确认写入。跨目标同名、自动v2/v3、禁止覆盖及逐目标失败反馈。直接ZIP不写同步目录。

## 历史使用流程（1.3.0，保存/导出限制已被上述1.4.0规则替代）

1. 双击根目录启动器，输入模板 ID 或上传文件，点击“评估模板”。本机读取并显示整批进度，完成后进入独立结果页。
2. 查看原、新缩略图及问题数量；打开“查看／编辑”同步查看两侧画板，点击问题坐标切换到上下问题层，问题牌以红框标示。
3. 可“一键修复全遮盖”：以本轮低扰动规则为准，按普通隐藏等量补位→少量内部重排→净增减不超过3张→最后塔内不超过6张的顺序搜索，默认上方删除同时比较下方/中间问题牌与整问题层压缩。非问题普通牌改动最多3张，主要为完全隐藏牌；整层压缩涉及的其他普通牌也计数。非塔投影并集及其余原露出面保护；塔自身外轮廓可延长，但锚点方向、等高组和严格高低关系保持且不盖住普通露出面。全部最终牌（包括塔）无悬空、无冲突、无全遮盖；来源、未知字段、数量、身份预算独立核验。重复修复按最初导入模板累计约束。有限搜索失败保留当前修订，不影响同批成功项；结果不是线上体验等效证明。
4. 使用与塔占比工具一致的编辑栏：层号减/加、无限制、单层查看、删除本层/删除本层以上（不含本层）；平移、复位、双向90°旋转、A/B计数与笔刷、删除、按坐标增删、撤回，最右“去编辑／退出编辑／保存编辑”随状态切换。指定层只增删该层；无限制显示全层、自动落层。方形锚点预示准确落点，右键删除，箭头键移动锚点、Enter/空格执行。编辑时不限制摆放，保存时检查坐标、同层冲突、悬空、总量及 A/B 三张成组；错误保留草稿并给出层号坐标。非编辑变换自动保存，已保存操作也能撤回（当前服务内最近50步，重新打开/刷新仍可用），撤回后旧ZIP失效，须重新导出。仍有全遮盖可保存草稿，但不加入修复通过的导出。
5. 设置批量命名规则并导出 ZIP；同名自动 v2/v3，源文件名称受保护，文件名与内部 ID 一致。失败项明确列出并跳过。刷新页面可恢复服务内尚存任务和已完成 ZIP 链接，不强制重复下载；关闭服务会清除内存任务，因此及时下载。
