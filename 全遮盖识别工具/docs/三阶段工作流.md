# 三阶段工作流

保留现有引擎、编辑器、报告、撤回、ZIP 和双仓可选同步。导入支持 50,000 个 ID 或文件，扫描进度单独轮询，牌面从内存中的原始模板按需解析。列表默认显示全遮盖，仍可筛选无问题及读取失败项；进入修改阶段后保留分页筛选、人工编辑和批量操作，可返回识别列表。

命名冲突在预览时分配 v2、v3 等，文件名与内部 ID 一致。默认写入工具下的输出模板目录。同步在用户确认已用 Git 拉取目标仓库后执行。预览明确列出仓库重名项，默认仅输出到本地，可逐项确认使用推荐名称同步。写入前后都检查目标文件，重名项独立跳过。

验收：大批 ID 与轻量进度、三阶段切换、两个导出入口的版本命名、同步确认和预览后出现同名文件、现有编辑与修复回归。

上传与模板 ID 均支持每批 50,000 项。实际文件分段传入本地服务，计入整批 256 MiB 和单文件 32 MiB 的上传容量。
