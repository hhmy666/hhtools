# 通关数据模拟

双击根目录的「启动通关数据模拟.command」，保持打开终端。需要 Python 3.11 或更高版本。工具在本机运行、读取模板和本地 ulinkconfig；模拟不会写回仓库、线上配置或资源。

## 导入与运行

- 可上传带表头的 `config_level` CSV/TSV，工具根据 `TemplateId` 和 `DupPara1–10` 识别模板与副本。上传整表时，可另外粘贴要实跑的模板 ID 或 LevelId 筛选。同名时优先匹配 LevelId。
- 可粘贴模板 ID 和每行 `A图案种类|Seed|塔副本幸运值|B图案种类`，支持并排与分开两列。分开时按顺序配对，两列数量应相同；重复 ID 会作为不同副本保留。
- 可只粘贴模板 ID，或上传独立模板 .bytes 文件。当没有副本参数时，设置目标消耗或目标裸胜率，用于比较实跑参数。A/B 默认每种图案 1–4 个三消组；两者独立计算。Seed 未设置时在 0–31 内随机取值。界面中可限制两者以及 Lucky、Seed 范围。
- 在设置里选择模板目录或手工输入路径。首次使用选择自己的仓库，后续保存在本工具运行数据中；上传的模板文件不依赖仓库。
- 默认每个最终输出副本实跑 1,000 局，覆盖至少 1,000 种由真实回放拟合的玩家风格。推荐模式先筛选参数，再对最接近目标的至多五套各自按要求局数复跑。结果按目标偏差排序，默认显示最接近的一套，其余可展开。推荐是有限搜索的结果。

## 指标与配置

- 裸胜率：模拟中未用道具、未复活、按原背包容量通关的比例。玩家的点击选择受局面变化影响，包括可点牌面、背包组牌、相近位置、结构牌和揭牌等特征。
- 人均消耗：按历史真实资源消耗校准。参考的是同产品、关卡、模板、副本和参数的历史配对样本格，并按模板留出核验，不能直接当作上线实测。
- 平均关卡时长：用回放中动作间隔估计，以分钟显示并保留两位小数。120 秒截断样本不用于拟合长停顿。缺少可用证据时会显示「—」。
- 失败 FUUU：失败且出现首个无解高压状态的模拟中，该状态出现在进度大于 50% 的比例。失败无解进度是这些出现无解高压的失败局的平均首个无解进度。
- 胜利 FUUU：成功且出现高压的模拟中，高压超过 3 次的比例。高压次数是成功且出现高压的模拟中的平均次数。高压计数参考客户端背包达到容量减 1 的记录。
- FUUU 档位：这是幸运值配置，与上面两个结果指标名字相近但含义不同。按自动发现的本机 ulinkconfig 仓库中 `config_level_list` 及 `config_client_level_fuuu_dup` 读取。只给模板 ID、无法匹配时，沿用幸运值第 1 档，不要求手填。

## 适用边界

旧 L 参考本地客户端的塔换牌分支，使用可读的模板和本机配置。线上实验开关、版本差异、账户 DDA/IAP 状态和事件不一定完整，结果会注明使用的假设。回放未上报的点错、无效触摸、设备帧延迟不能从点击间隔倒推出真实误触；不把这类假设当观察值。裸胜率存在采样噪声和模型误差，尤其是塔、道具与版本差异的情况。不要只看两套参数的极小差异来决定上线。

模板解析、几何、发牌和点击引擎均内置于 scripts/sim_core，无需安装关键结构工具或玩家行为工具。模型随包存放于 resources/models；运行数据只保存本机设置，不含发布模型。

## 模型范围与已知偏差

内置匿名玩家策略系数、时长/道具倾向和消耗校准汇总，不包含真实玩家账号、逐局回放或原始 CSV。模型来自历史数据，存在样本筛选、版本差异和整局胜率低估；点选偏好拟合的改善不代表裸胜率或消耗误差同比下降。不能将模拟结果当成线上实测，也不能仅凭两套参数的极小差异决定上线。账户 DDA/IAP、活动和未上报的局内状态尚不能完整还原。

## 分享给同事与本机路径

复制整个工具文件夹，或运行 `python3 scripts/build_release.py` 生成 `发布包/通关数据模拟.zip`。发布包不含你的模板路径设置、缓存、模拟记录或其他工作区文件。解压后使用 macOS 启动器；需 Python 3.11 或更新版本，仅使用标准库，无需安装第三方 Python 包。目录含空格和中文也可以使用。

模型固定放在 `resources/models/`，不要放到 `运行数据/`；不要只复制启动器。同事上传模板或选择自己的模板仓库。模型属于公司内部训练资产，按公司内部协作范围分享。

配置仓库参考玩家行为工具的本机配置方式，按当前用户发现路径，不写死用户名。优先读取 `~/ulinkconfig/csv`；否则在用户目录以及 Projects、projects、repos、Repositories、work、Workspace、Developer、Documents、Desktop 下有限层级查找包含 ulinkconfig 名称的仓库。仅找到唯一完整仓库时自动采用，不遍历整盘。要求包含 config_client_game、config_client_level_fuuu_dup、config_client_tile、config_client_level_tile、config_level、config_level_list 六张 CSV。

仓库在其他位置，或同时存在多份配置时，可显式指定（支持仓库根目录或 csv 子目录）：

```sh
TILE_SIM_CONFIG="/你的路径/ulinkconfig" ./启动通关数据模拟.command
```

也可用 `python3 scripts/app.py --config-dir "/你的路径/ulinkconfig" --open`。显式路径无效时会说明缺少的表，不偷偷改用其他仓库。未发现配置不影响打开工具，开始模拟前会提示如何指定。读取的是同事本机版本，不代表当前线上生效配置；不会复制或写入其配置仓库。

开发核验：`PYTHONPATH=scripts python3 -m unittest discover -s scripts/tests`。独立性测试会把工具复制到临时路径，隔离 Python 搜索路径，模拟同事的配置仓库并实跑 1,000 局、1,000 种玩家风格。

首次安装 Python：已有 Homebrew 时，在终端依次执行 `brew install python@3.13` 和 `python3 --version`；若启动器仍找不到新 Python，请重新打开终端。没有 Homebrew 时，从 [Python 官网](https://www.python.org/downloads/macos/) 安装 macOS installer。启动后保持终端窗口打开。

macOS 若提示 Apple 无法验证启动器，先点「完成」，再到「系统设置 → 隐私与安全性」对确认来自此仓库的启动器点「仍要打开」，按提示确认。无需关闭系统整体安全检查。

SourceTree 更新：先关闭工具终端 → 拉取 `origin/main` → 重新双击启动器。个人路径在本机运行数据内保存，不随 Git 上传。
