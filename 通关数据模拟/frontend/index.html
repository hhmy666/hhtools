    使用说明

    导入关卡

    上传 config_level 的 CSV，或粘贴模板 ID 和副本参数。参数和 ID 可逐行并排，也可分成两段按顺序粘贴。重复的 ID 可对应同一模板的不同副本。

    只有模板 ID 时，先在「模板仓库」选定目录。也可以直接上传 .bytes 模板。

    设置模拟

    提供参数时按每组指定参数模拟。缺少参数时，工具会在 A、B 单图案组数各 1–4 的范围内取样。可以调整范围和随机种子，也可以用预期人均消耗或裸胜率作为推荐目标。

    查看结果

    各指标按模板和副本展示。裸胜率指未使用道具或复活就通关的局占比。模型和抽样信息会随结果一起显示。

    幸运值使用旧版 L，按本地 ulinkconfig 的关卡列表和配置匹配 FUUU 档位。没有可用映射时使用档位 1。

    失败 FUUU 为出现无解的失败局中，无解进度超过 50% 的比例。胜利 FUUU 为出现高压的胜利局中，高压次数超过 3 次的比例。没有可计入分母的局时显示短横线。
