# 玩家行为分析工具｜设计系统

## 设计方向

延展“关键结构生成工具”的视觉语言：安静、精确、可信。整体 80% 使用克制的白色与冷中性色，20% 使用蓝色强调关键任务。界面优先呈现数据能否使用、当前进度和可复核结果，不用装饰性大图或营销式文案。

## 字体

- 英文、数字：`Inter Local`，本地文件 `frontend/assets/fonts/InterVariable.woff2`。
- 中文：`Source Han Sans SC Local`，本地文件 `frontend/assets/fonts/SourceHanSansSC-VF.woff2`。
- 表格数字启用 tabular nums；不依赖 CDN 或系统字体。

## 布局与层级

- 固定 68px 顶栏：品牌、本地服务状态、使用说明。
- 桌面端 196px 左侧栏：分析工作台、结果概览、运行记录、设置。
- 主区最大宽度 1500px；五步流程轨位于任务上方。
- 页面标题和辅助标题只使用中文，不添加装饰性英文眉题；CSV、TileNum、字段名等业务术语按实际名称保留。
- 导入阶段采用 2:1 双栏：左侧文件/粘贴主任务，右侧数据要求与路径检查。
- 分析进行中使用纵向全宽任务卡与日志卡：任务卡显示后台返回的真实百分比或已处理数量，日志卡完整换行展示最近记录；不根据时间或前端动画伪造进度。
- 结果阶段先给 KPI 与结论，再给可筛选预览表，最后给导出与审计入口。
- 同一步骤始终只保留一个页面级主标题；完成态直接替换该标题，不在结果区重复叠加大标题。
- 760px 以下隐藏侧栏，保留顶部品牌、步骤轨与单列卡片。

## 组件规范

- 主按钮每个任务区最多一个，蓝色实心；次按钮白底蓝边；危险操作红色且必须说明影响。
- 表单控件高度 42–46px，卡片内边距 20–24px，间距遵循 4px 基准。
- 上传区支持点击与拖拽，文件名、大小、读取状态单独显示；粘贴模式提供字符/行数。
- 行为分析完成后仍提供“追加玩家样本”；当前浏览器会保留已选文件，新增文件与原文件合并预检，旧结果在预检通过后失效并等待按全部输入重算。
- 线上指标阶段明确提供两种关卡标签聚合口径：“全部首局实例玩家加权”和“进入人数最多副本代表”；结果区必须同时展示最终标签、另一口径标签及代表副本来源，避免方法切换后失去可追溯性。
- PX / PS 问题关不参与自动排位，但不阻断配置副本导出；保留其原关卡位置为空，其余关卡继续排入可用位置，并在界面与工作簿中明确标注空位原因。
- 状态不能只靠颜色，必须同时有文本或图标。
- 表格首列与表头在可用时保持固定；长文本截断并提供 title。
- P0–P5 / PX 排关压力标签沿用固定色，但标签内同时显示代码和中文名，避免只靠颜色识别。T0–T7 仅在内部诊断/审计中显示。
- 异常指标未达到“多维高压力＋极端失败流失”联合门槛时仍正常排位；主表和副本表使用独立“风险备注”列保留问题证据，不能用警示色或空位暗示已经确认极端负面。

## 签名元素

“分析轨迹”是本工具的签名元素：五步流程轨与结果摘要使用同一条细蓝色纵/横线串联，从“输入可用”一路到“配置副本”，让用户一眼看出结论是如何从证据逐层生成，而不是一个黑盒评分。

## 可访问性与响应式

- 正文与背景对比度达到 WCAG AA；焦点环使用半透明蓝色 3px。
- 所有交互元素可用键盘访问；原生 dialog 支持 Esc 关闭。
- `prefers-reduced-motion` 下关闭位移动画和非必要过渡。
- 1439/1180/760/480px 四档响应式；窄屏表格允许横向滚动，不压缩到不可读。
