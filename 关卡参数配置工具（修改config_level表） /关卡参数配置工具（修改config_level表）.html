参数修改规则说明

规则0（通用规则/默认规则）：从副本2开始：ATile 立刻 -1，然后每 2个副本再 -1；从副本3开始：BTile 立刻 -1，然后每 2个副本再 -1。

若填 DupParaN(N≥2)：从副本N起 ATile 先 -1，之后每2个副本再 -1；从副本N+1起 BTile 先 -1，之后每2个副本再 -1。

ATile ≤ 4 或 BTile ≤ 3 时不再减少；若初始值本就小于阈值，则保持原值不被抬高。

规则1：先修改已粘贴的副本参数，其余副本从上一个副本复制参数。

示例：只填 DupPara1，则 DupPara2~10 全部复制 DupPara1。

示例：填 DupPara1、DupPara2，则 DupPara3~10 全部复制 DupPara2。

示例：只填 DupPara2，则 DupPara1 不改，DupPara3~10 全部复制 DupPara2。

规则2：先修改已粘贴的副本参数，再按副本递增递减 ATile/BTile。

若填 DupPara1：副本1与副本2保持一致；从副本3起 ATile 先 -1，之后每3个副本再 -1；从副本4起 BTile 先 -1，之后每3个副本再 -1。

若填 DupPara2：副本1不改；从副本3起 ATile 先 -1，之后每3个副本再 -1；从副本4起 BTile 先 -1，之后每3个副本再 -1。

若填 DupParaN(N≥3)：从副本N起 ATile 先 -1，之后每3个副本再 -1；从副本N+1起 BTile 先 -1，之后每3个副本再 -1。

ATile ≤ 4 或 BTile ≤ 3 时不再减少；若初始值本就小于阈值，则保持原值不被抬高。

规则3：每1个副本递减一次（步长=1）。

从副本3起 ATile 先 -1，之后每1个副本再 -1；从副本4起 BTile 先 -1，之后每1个副本再 -1。

若填 DupParaN(N≥3)：从副本N起 ATile 先 -1，之后每1个副本再 -1；从副本N+1起 BTile 先 -1，之后每1个副本再 -1。

ATile ≤ 4 或 BTile ≤ 3 时不再减少；初始值小于阈值不会被抬高。

规则4：每2个副本递减一次（步长=2）。

从副本3起 ATile 先 -1，之后每2个副本再 -1；从副本4起 BTile 先 -1，之后每2个副本再 -1。

若填 DupParaN(N≥3)：从副本N起 ATile 先 -1，之后每2个副本再 -1；从副本N+1起 BTile 先 -1，之后每2个副本再 -1。

ATile ≤ 4 或 BTile ≤ 3 时不再减少；初始值小于阈值不会被抬高。
