# 塔占比修改及增加Btile工具

支持减少与增加两种模式。减少模式把塔内 Tile 移回非塔区域，降低塔占比并保持总量；搬出的牌可按补牌规则转换 A/B 类型，补牌保留原模板的主要对称形式与非塔堆叠方式。增加模式追加普通 A/B Tile，新建塔或为原塔加层。两种模式最终 A、B 数量各自为 3 的倍数。

输入模板 ID 或选择文件后，点击导入卡底部的“去增加塔”或“去减少塔”，读取完成后进入对应配置，共用“导入模板 → 配置参数 → 导出模板”三步。减少模式沿用原参数；增加模式只追加普通 A/B Tile，可新建塔或为原塔加层，完整说明见下方“增加塔：推荐、预览与微调”。

日常使用双击根目录的“启动塔占比修改及增加Btile工具.command”。网页右上角“使用说明”提供完整连续正文；左侧目录只跳转章节，右侧可以从头向下阅读，滚动时目录会跟随标记当前章节。也可搜索按钮名、参数名或遇到的问题。工程目录仍沿用历史路径，不影响既有模板与配置位置。

## 1. 准备输入与目录

### 怎么操作

1. 双击启动器，保持启动窗口运行。
2. 工具会查找两个模板库；核对路径后点击“确认使用”。
3. 路径不正确或没有找到时，点击“修改路径”，在“设置”中填写目录并“保存设置”，再确认。

| 目录 | 用途 | 正确目录的结尾 |
| --- | --- | --- |
| Tile 仓 | 按模板 ID 读取，也可作为同步目标 | `tile/Tile/Assets/Resources/TileMatchLevelData` |
| 模板仓 | 按模板 ID 读取，也可作为同步目标 | `tileleveltemplate/Template` |
| 导出目录 | 存放已验收的新模板 | 默认是工具内的“输出模板” |

每台电脑的路径前缀可以不同。发现多个候选时，请选择这次项目使用的目录；修改路径后需要重新确认。自动发现未完成或结果不全时，可以直接手动填写。

### 完成检查

- 模板库指向当前项目，不是旧项目或备份。
- 本机服务已连接。
- 如果只上传文件，可以先完成导入；按 ID 导入与同步需要先确认所选模板库。

## 2. 建立模板清单

### 怎么操作

1. 有本地模板库时选择“输入模板 ID”；只有文件时选择“上传模板文件”。
2. ID 方式先选择“读取来源”：Tile 仓或模板仓，再粘贴模板 ID，一行一个。例如 `mxd0057v1`；无需填写 `_m.bytes` 后缀。
3. 上传方式可选择或拖入一个、多个 `_m.bytes`，也可分多次追加。
4. 点击“去增加塔”或“去减少塔”。两个入口都会先读取当前输入，再进入所选配置；不需要另点解析。可一次输入或选择全部模板，不必手动拆为每批 20 个；界面显示实际已读取数量和当前内部批次。
5. 读取完成后自动合并为一个批次，跨批重复内容统一去重。核对逐模板结果后继续配置。

ID 方式只读取所选、已确认目录内的精确文件 `<模板ID>_m.bytes`。找不到时请检查 ID 与来源选择，工具不会静默换到另一仓库。两种导入方式都会读取文件内部的 TemplateId，源模板保持只读。

网络中断时，已完成的内部批次保留在当前页面，再次点击原入口只重试未完成部分；若合并失败，仅重试合并。修改输入或读取来源会重新建立批次；刷新页面、重启服务或“重新开始”后需重新导入。不要在解析过程中修改模板库内容或绑定路径。

模板总数量不再有 20 个限制。内部每次最多读取 20 个、单次请求最多 128 MB，上传按数量与大小自动拆分，ID 读取遇到大批次会继续拆分；单文件最多 32 MB。超出单文件大小时检查是否选错文件，与模板总数量无关。建立生成任务时逐文件校验并保存源快照，不将整批文件同时加载进内存。

### 完成检查

- 需要处理的模板已进入清单。
- 内部 TemplateId、A/B 数量、塔堆数量与各堆数量符合预期。
- 单项错误已处理；正常模板仍可继续。

### 按需了解：检查结果

解析会统计总 Tile、A/B Tile、塔占比、非塔层数、主要对称形式和堆叠形式。相同内容不会重复计算；解析失败项显示具体错误，不以 0 补写结构统计。原减少模式的无塔处理沿用原规则；增加模式可对无塔模板新建塔。

导入只负责读取可解析的模板，不用新增牌的规则限制原模板。原有跨层堆叠、层号间隔、边界或重叠会原样保留，仅记录提示；不搬的牌保持原坐标、类型、字段和字节。不会为了通过检查而自动修理原阵型。

减少模式生成时验证本次搬移：补牌不得新增同层冲突、越界、全遮盖或不合法堆叠，且总量、对称等规则仍须满足。无法安全确定塔成员、缺少新位置的边界信息或无法完成目标时，会说明具体搬移原因，原模板不受改动。增加模式另验收追加牌与授权的位置、方向或整体平移。历史已验收模板用于回归验证，不是可导入模板的白名单。

## 3. 减少模式：配置塔与补牌

点击“编辑统一方案”设置批次默认参数；只有例外模板需要“单独设置”。“恢复批次默认”会移除该模板的覆盖值。左侧导航按“优化工作台 → 运行记录 → 增加Btile工具 → 一键配置新参数 → 设置”排列，窄屏底部导航沿用相同顺序。

### 参数选择依据

| 参数 | 默认值 | 怎么选择 | 规则性质 |
| --- | --- | --- | --- |
| 塔 Tile 占比下限 | 0% | 结果可等于下限，控制至少保留的塔占比 | 可填 0–100%；正上限时下限需小于上限 |
| 塔 Tile 占比上限 | 25% | 结果必须严格小于所填值；上下限都填 0 去除全部塔 | 可填 0–100%；减少塔时不得高于该模板原塔占比，0 是清空塔目标 |
| 非塔补牌类型 | 自动 | 单模板“单独设置”或重跑时可选自动、补 A、补 B | 自动沿用原全局数量规则；明确选择按所选类型补入 |
| 单层非塔 Tile 建议上限 | 20 | 控制补牌后的单层密度；空间不足时可适度提高 | 正整数；20 是默认值，不是固定硬上限 |
| 最多新增层数 | 2 | 控制最多增加多少层；不想加层时填 0 | 非负整数；2 是默认值，不是固定硬上限 |
| 补牌位置策略 | 顶层优先 | 根据希望改变表层还是底层选择 | 四种方式均保留几何与数量规则 |
| 塔保留方式 | 按占比自动分配 | 默认保持原塔堆数量关系；想明确控制每堆时选高级逐塔 | 手动数量也需要满足占比与验收 |
| 随机种子 | 1 | 随机策略下固定某次结果 | 整数；同源文件、参数、种子与工具版本可复现 |

### 必须理解：塔占比区间与数量守恒

塔占比 = 塔内 Tile 数 ÷ 模板全部 Tile 数。默认区间为 **0% ≤ 塔占比 < 25%**，等于 25% 不通过。下限可等于实际结果，上限始终严格；例如下限 10%、上限 25% 表示结果至少 10% 且小于 25%。正上限时下限等于或高于上限不可提交；清空塔时上下限都填 0。

这里的25%只是默认上限，不是硬限制或固定目标；可设置0–100%，减少塔时逐模板核对上限不高于各自原塔占比。例如原35.4%可设27%，原20%不可设27%；混合批次需单独设置，不自动压低显式输入。自动模式第一组塔保留数量无法补牌时，会在原区间、补牌类型、补牌策略、单层牌数和新增层数不变的条件下继续尝试其他合法保留组合，找到合规结果就直接完成。例如实际23.2%也满足默认区间，不需要修改上限才能生成。高级逐塔模式严格使用你填写的数量，不自动换组合；实际占比也须落在区间内。

自动摆放有尝试时限和次数保护，防止单个模板持续占用本机；不是费用，也不是需要购买的额度。未完成不等于无解。失败提示区分“本次试算未完成”和“本次未找到完整补牌方案”。能够汇报数量时，会写明本次需要摆放、已排下、尚未排下的张数；这些是试算结果，不代表棋盘最多只能容纳这么多牌。

移出多少塔 Tile，就补回多少非塔 Tile，不增加总牌量。“自动”保持原规则：只有 A 的源模板全部补 A，只有 B 的源模板全部补 B；A/B 都有时，全部补原模板总数较少的一类。A/B 同数时使用确定性选择，并显示实际补牌类型。单模板明确选择“补 A”或“补 B”后，以所选类型补入。

单模板编辑与重跑会按原模板的**非塔**数量给出推荐：只有 A 或 A 更多推荐补 A，只有 B 或 B 更多推荐补 B；两者同数说明均可，没有非塔数量证据时不给类型推荐。这是选择参考，与“自动”的全局数量规则不同；只有点击“采用推荐”或手动选择才改变补牌类型。切换模板和填入已验收参数建议均保留独立选择。

明确补入原模板全局不存在的类型时，原 B 为 0 的新增 B 使用下文“一键配置新参数”的新 A 组数基准、向上取整后减 1 且最低 3 的规则；新增 A 而原 A 为 0 仍需单独确定基准。生成须满足总量守恒和最终 A/B 各为 3 的倍数。

塔顶按连续后缀移出，搬出的原牌可以是 A、B 或混合类型；搬出类型与补入类型分别计算。只允许对本次搬出的牌转换 A/B 类型，不搬的牌保持原类型、字段和字节。最终 A、B 数量可以与原模板不同，但各自都需为 3 的倍数。

自动分配会联合检查各堆保留数、搬出 A/B 数、补入类型、转换后的三消数量与合法位置。高级逐塔严格采用所填保留数；若转换后 A/B 不是 3 的倍数，会显示具体数量原因，并仅提供已经生成且通过独立验收的保留数调整方案，不擅自更改输入。

### 四种补牌方式

非塔补牌类型另外支持“以 A Tile 为主”“以 B Tile 为主”“与原搬出牌类型一致”。“为主”在最终 A/B 各自为3的倍数前提下，尽量补入所选类型，通常最多保留0–2张另一类。例如原剩余牌量余数允许时，搬出31张A、以B为主得到30张B＋1张A。少数补位需三维坐标邻近原非塔同类（距离平方不大于8），不限制同层左右；没有原同类且需要少数补位时，无法满足该要求，不按通过交付。“与原搬出牌类型一致”逐张保留搬出牌类型。旧自动和全部补A/B语义不变。

### 在对比窗口手动微调

验收结果表的“批量居中新模板”位于“批量修改参数并重跑”左侧，处理本批全部已生成、已验收的新模板，不受勾选范围影响。按普通牌与展开塔的可见整体外框平移至画布中心；受整数网格或安全边界限制时取最近合法位置。仅平移并逐项自动验收保存，不重新摆牌；独立进度条显示百分比、已处理/总数与当前模板，全部保存并刷新结果后才到100%。单项失败保留原因并继续其余模板，进度结束不等于全部成功；已居中项直接跳过，成功保存后旧导出预览失效。

失败的减塔模板在“单独调整并重新运行”下方提供“删除所有塔并手动补牌”。点击只创建清塔预览，不修改原文件或发布未验收产物；右侧删除全部塔及塔内牌，普通牌保持原样。点“去编辑”后可以手动补牌，也可以不补牌直接“保存编辑”。只清塔本身算待保存改动，不要求恢复原数量；总数及A/B各自为3的倍数、最终结构验收通过后，才能下载或导出。取消关闭不替代原结果。已保存的清塔结果可继续平移、增删与导出改名。

自动补牌优先识别原非塔区的表面和投影轮廓规律，不再仅依据全部XYZ牌是否严格对称；对有左右或中心旋转规律的表面优先成组摆放，严格源对称仍保留。美观是软优化，不免除承接、安全区、三倍数和类型邻近要求。邻近检查纳入布局回退，不再只检查第一套完整摆法。普通搜索未完成时继续扩大搜索并显示状态。原模板已有的相邻层“一压一”允许原样保留并导出，但补牌避开这些位置且不能新增“一压一”；结果提示具体层数，编辑画布红框标记，供用户修正。

验收结果的“阵型对比”中，平移、偏移、A/B笔刷、删除、撤回图标、坐标工具和右端编辑按钮位于同一行。非编辑平移自动验收并保存；“去编辑”展开笔刷，无改动时右端为“退出编辑”，有改动时变为“保存编辑”，统一提交增删和平移并验收。层级与Unity编辑器对齐：默认“无限制”显示全部层，不能单层查看；新增在落点2×2区域最高牌上方自动落层，空白处放底层，右键删除实际点中的牌。选择第N层则增删仅在第N层进行，默认累计显示至该层，也可勾选“仅看当前层”。编辑鼠标显示一张Tile大小的方形网格锚点及目标层，预览与点击共用落点；删除画笔用红框标目标。支持图标撤回、删除画笔与网格图标下的X/Y坐标增删。所有显示范围内未被更高层牌压住的牌均高亮，原模板始终只读；编辑中不拦截几何问题，保存时统一核验。

已保存的平移或增删在结果表“已通过”右侧标为“已微调”，重新生成后清除。关闭对比返回原列表位置。状态右侧“预览图”列显示原/新模板的真实缩略图，新产物自动更新；点击可看完整阵型。新增牌锚点使用安全区，原模板已有的边缘牌可保持但不能进一步外移；真实画板及塔展开边界仍严格限制。某一方向达到边界不影响其他合法方向。

导出确认显示文件总数与待写入数。点击“预览导出”后立即开窗，先准备并复核各模板；确认写入后再复核并显示后端真实已处理/总数。列表独立滚动，底部进度和操作始终可达。没有可度量工作时不伪造百分比或剩余时间；等待时不要关闭工具。网络响应丢失时继续查询同一次写入任务，不重复发起导出，也不会因为重试多生成v2文件。

“以A/B为主”的少数补位采用三维欧氏距离：与原非塔同类牌的 `dx²+dy²+dz²≤8` 即为邻近，可以跨层。必要的0–2张少数补位允许安排在邻近同类的已有低层，其余牌仍遵循所选补牌方向；承接、安全与新增遮挡限制不变。hr0127回归示例：移除37A、补入1A36B，少数A `(4,2,5)` 与原普通A `(4,4,3)` 跨两层邻近。

右图即时显示未保存草稿，支持逐步撤销。A/B笔刷分别显示全部层及塔内总数和补到下一个3的倍数还差的张数，如107 (1)、108 (0)、0 (0)，增删与撤销后即时更新。编辑阶段不拦截重叠、悬空、一压一、暂时越界、删塔中间层或特殊牌，可先自由调整；仅校验输入为有效整数等技术格式。点击保存才统一核验，总量与A/B各自为3的倍数，承接、边界、塔连续性等通过后才替代已验收产物；失败显示问题牌红框、层号和坐标，保留草稿。继续编辑会清除上次保存提示。“一压一”仅指相邻两层同XY完全重合，隔层同坐标不算，不禁用整列。原有相邻覆盖可保留并提示，新增相邻覆盖保存时需修正。微调允许偏离原自动数量/占比目标。

结果勾选同时用于批量改参、预览导出和模板ZIP：有勾选时只交付其中的已验收产物，不勾选时交付全部已验收产物；只选失败或无需修改项时不会自动扩大为全部。改变勾选会使旧导出计划失效，需重新预览。导出页修改命名只生成当前验收内容的身份副本，改变导出/ZIP文件名与内部ID，不重新摆牌、不替代微调或当前产物；未编辑命名时保留各模板原有自定义名称。同步仍使用当前验收产物名称。页面显示当前范围及不可导出的原因。

编辑区显示“原模板 / 新模板 Tile 总数”，总数覆盖全部层及塔牌。悬空等可定位问题在新画布用红色实线边框和感叹号标记；保存失败用红色文字和浅红底提示，保留草稿。保存会定位首个问题层，“定位问题 Tile”还可滚动到该牌；修复或撤销后标记自动消失。三倍数等整体数量问题显示具体提示，不虚构问题牌。

保存经过服务端独立读回验收后才成为新产物。失败保留草稿及原已验收产物；另一个窗口更新后拒绝过时草稿，不覆盖新版本。有未保存修改时，点击右上角叉或退出编辑会弹出“继续编辑 / 关闭不保存 / 保存后关闭”；保存失败不会关闭，数量不合法时说明原因并允许直接关闭不保存。保存中禁止重复操作。微调保存后重新预览导出/同步；下载、重命名、重启恢复和一键配置新参数均读取最新可信产物及实际A/B数量。重新生成仍基于原导入快照，会取代手动微调，不累加到微调结果。

| 策略 | 主要变化 | 适合什么时候 |
| --- | --- | --- |
| 顶层优先 | 先补顶部较空的若干已有层，再在允许范围内向上增加层 | 顶部范围随阵型调整，不固定一层或两层 |
| 底层优先 | 先补底部较空的若干已有层，再在允许范围内向下增加层 | 下加层须承接原底部全部牌 |
| 五五开 | 上下都参与，尽量平衡补入张数，不要求层数相等 | 可顶部多层、底部一层，也可上下加层 |
| 随机 | 全部已有层及允许的上下新增层都可参与，固定种子可复现 | 尝试整个阵型的合法分布 |

美观是每种补法共同的软优化：满足数量、方向与全部硬规则后，尽量让各层牌数差距不过大，尤其避免顶部、底部过空；不新增“美观”选项，也不强制所有层数量一致。顶层/底层优先不会为凑数静默换到相反一端。下方新增层时，原非塔牌层号统一上移，原塔不动；下层必须承接原底部全部牌，补牌不足以形成完整承接时不能强行下加层。

首轮顶部/底部方案补不齐时，会在原参数不变的条件下回溯原有各层（包括中间层）及允许的新增层，重新分配完整对称组；“最多新增层数”不限制使用原有层。每关闭一层先检查其是否承接紧邻上层，最终由独立验收再次检查整副模板。搜索未完成仍只表示本次未完成，不是无解证明。

### 按需了解：高级逐塔与几何规则

- 按界面塔堆顺序填写每堆保留数，使用非负整数；保留数不能多于原堆数量。全部填写后仍须符合目标占比与对称关系。
- 自动方式尽量保留原塔堆关系。例如原来 `6 / 9 / 9 / 6`，优先缩为 `3 / 4 / 4 / 3` 这类分布；目标为 0 时清空全部塔。
- 顶部补牌至少压住邻近下层 Tile 的 1/4 角；底部补牌至少被邻近上层压住 1/4 角。单 Tile 的相邻层全遮与非法位置会被拒绝。
- 优先沿用原层四分之一角或二分之一的堆叠形式；风格统一是软目标，不是额外的可行性硬限制。优先方案未完成时，继续尝试其他部分重叠组合；接触张数或重叠单位不同不会直接被当成无解。无悬空、相邻一压一全遮盖禁止、边界、对称及数量约束保持硬性验收。
- 必要承接链优先尝试左右成对的牌，尽量避免中间单独一张牌连续向下形成细杆；单张仍作为合法回退，不把美观偏好变成额外失败条件。仅新生成方案采用此排序，不自动改写已有模板。
- 补牌按镜像或完整对称组放置。原阵型存在左右对称时，以左右对称为硬约束，不额外强制同时保持上下或180°对称；其他阵型仍沿用真实成立的对称形式。同层及相邻层的堆叠统一属于软优化。
- 随机策略会检查全部已有层及允许的上下新增层。所有策略都会检查源普通牌的支撑缺口，回溯尝试补完整承接链，再按所选方向分配剩余牌；不能仅给缺口上方加层就算成功。顶层/底层优先只允许这些必要承接牌超出原先确定的顶部/底部范围，不借此把剩余牌静默换到另一端。第 1 层新牌不需要接触上层，较高层新牌必须有紧邻下层承接。下层刚补上的牌与原有牌一起组成承接面。相同源文件、参数、随机种子和工具版本可复现。
- 新补 Tile 锚点安全区为 X=2–14、Y=2–16，2×2 占位不能越过模板边界。增加层数不会放宽左右显示范围。

### 完成检查

- 本批次目标占比与补牌策略符合策划意图。
- 例外模板已单独设置，未误改整批。
- 高级逐塔数量完整且可行。
- 点击参数卡片下方的“开始生成”；工具仍会独立验收。

## 4. 生成与复核结果

### 怎么操作

1. 点击“开始生成”，等待任务逐模板处理与独立验收。
2. 先看通过、失败、无需优化数量，再核对新 ID、占比、各堆保留数、搬出/补入 A/B 数量、A/B 增减、原/新总量及新增层数。
3. 失败项展开原因，点击“单独调整并重新运行”；优先只调整建议涉及的参数。
4. 点击“阵型对比”，查看原、新阵型及搬移牌，按需分层检查；在项目编辑器复核后继续导出或同步。

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 已通过 | 当前产物通过独立验收 | 复核外观后下载、导出或同步 |
| 无塔，已跳过（减少模式） | 原模板没有塔牌，不命名、不生成文件 | 可查看原模板；增加模式可新建塔 |
| 失败 | 本次未得到满足全部规则的结果 | 阅读原因，单独修改与重跑 |
| 部分成功 | 同批次中既有成功也有失败 | 成功项继续，失败项分别处理 |
| 已中断 | 上次运行被服务重启打断 | 从运行记录打开，单独重跑未完成项 |

### 阵型对比

原模板与新模板使用相同的编辑器固定坐标和比例。17×19 网格点的 X/Y 奇偶相同为红点、不同为蓝点，塔按照编辑器方向和位移展开。浅色表示当前显示范围内完全无遮盖，灰色表示有遮盖；四分之一角被压住也不高亮。金色虚线标记实际挪动的 Tile；可展开全部搬移坐标。

不再提供“显示方式”下拉，层级切换左右同步；指定层默认累计显示至该层，也可仅看当前层。显示层号为原始Z+1，坐标表的Z保持原值。A、B仅代表模板牌类型。预览不含运行时随机图案、动画和设备适配，不能替代实机验收。原模板文件保持只读。

打开默认“无限制”，显示全部层，增牌自动落层、删牌作用于点中的牌，不能仅看单层。选择具体层时，增删只在该层进行；可以累计显示至该层或仅看当前层。完全未被显示范围内任何更高层牌压住的牌均高亮，包括下层普通牌和塔牌。有改动点“保存编辑”统一验收，失败保留草稿和原产物；关闭时仍可继续编辑、关闭不保存或保存后关闭。

平移右侧可顺/逆时针整体旋转90°，绕画布中心，塔方向同步。非编辑平移、旋转验收后自动保存；撤回箭头可还原最近一次已保存微调。编辑中所有增删、平移、旋转共用草稿和单步撤回。选择具体层后，同排可“删除本层”或“删除本层以上”：以上不含本层，包含隐藏高层；确认窗口列出实际张数，删除先改草稿，保存验收后生效。无限制时整层删除不可用。两条工具栏各保持一行，窄屏仅工具栏局部横向滚动。

### 必须理解：独立验收证明什么

验收从新 bytes 重新读取，复查内部 ID、最终 A/B 各为 3 的倍数、塔占比、坐标、遮挡、对称与堆叠。减少模式核对原/新总量一致、搬出/补入数量与类型转换、各堆保留和未搬牌字段；增加模式核对追加数量、逐塔最终数量与授权变化。通过后才进入可下载、导出和同步清单。它证明模板结构符合这些规则；改后的玩家体验仍应结合客户端复核与实际测试。

单独重跑只处理当前模板，其他通过项保留。其他模板正在运行时也可提交，后台在同一任务队列中依次处理；同一模板已排队或运行时不能重复提交。重跑后以新一次的有效产物为准，旧产物不会继续作为当前下载结果。

结果表左侧可勾选多个模板，或点击“选择失败项”，再点击“批量修改参数并重跑”。弹窗以首个选中模板的参数为起点，结构参数统一应用；各模板自己的命名及高级逐塔保留数不被覆盖。提交后逐项显示排队和运行状态；部分请求未确认时保留这些项，可重试，不重复提交已接受的模板。切换到另一任务会清空选择。

### 失败后怎样修改参数

减少模式失败时自动试算最多两个可用方案，每个方案都生成新 bytes 并通过独立验收，再显示“参数旧值 → 新值”、保持不变的参数，以及实际塔占比、搬出/补入 A/B 数量、A/B 增减、原/新总量和新增层数。高级逐塔的数量错误可建议具体保留数，仍以完整生成和验收通过为前提。试算只在内存中进行，不注册可下载文件、不导出或同步模板。

减少模式优先保留当前补牌策略，检查新增层数、单层牌数及组合调整；必要时降低塔占比，再尝试其他补牌方向。塔占比上限和实际塔占比均不高于本次原方案，不放宽对称、遮挡、堆叠或数量守恒规则。没有两个通过方案时不凑数；搜索受状态和时间预算约束，未找到不等于全局无解。

在“单独调整并重新运行”中点击“填入方案一/二”，核对后再“重新生成并验收”。填入不会自动执行，保留未调整的占比下限、补牌类型与命名；手动再改参数后需要重新验收。重跑预填当前模板实际区间与类型，旧记录缺失的新参数按下限 0%、自动补牌兼容。旧任务没有方案记录时，单独重跑获取新建议。

旧任务若提示“塔顶无法只搬一种类型”或把此原因显示为“未知错误”，使用原参数单独重跑。该提示来自旧版错误地要求搬出与补入同一类型，并不证明当前规则下无法完成。已验证的 `hr0127` 在 25% 上限、顶层优先、单层 20、最多新增 2 层下，塔牌 37 → 19，总量 108 → 108，A 69 → 51、B 39 → 57：搬出 18 A、补入 18 B，新增 2 层并通过独立验收。这个例子说明类型转换口径，不能替其他模板提前判定可行。

### 完成检查

- 所需模板已通过；失败项已处理或暂时排除。
- 新占比、搬出/补入或新增数量、A/B 增减符合预期；减少模式原/新总量一致，最终 A/B 各为 3 的倍数。
- 客户端编辑器中显示范围、对称和堆叠符合预期。

## 5. 命名与导出到本地

### 怎么操作

1. 核对新模板 ID。减少默认 `lessT{原模板ID}`，增加默认 `moreT{原模板ID}`；例如减少时 `mxd0057v1` → `lessTmxd0057v1`。
2. 按需修改本批次“命名规则”和“导出目录”；默认值在“设置”维护。
3. 修改命名后直接点击“预览导出”；导出只改文件名与内部ID，不重新生成阵型，保留当前微调。ZIP使用同一导出命名规则。
4. 在导出预览中核对最终名称；同名自动加 v2、v3 等后缀，最后点击“确认写入”。

成功后显示“导出成功”弹窗，列出实际目录。点击“打开输出目录”可在访达中查看；弹窗不自动消失，用右上角关闭按钮、“我知道了”或 Esc 关闭。页面仍保留写入、跳过与失败结果。

| 预览结果 | 怎么处理 |
| --- | --- |
| 新文件 | 确认目标目录与名称后写入 |
| 已有同名文件（内容相同或不同） | 自动加 v2、v3 等后缀，不加下划线，不覆盖 |
| 减少模式中未生成新文件的无塔模板 | 跳过；增加模式的已验收产物可交付 |
| 目标变化或计划过期 | 重新预览并核对，使用新计划 |

### 按需了解：命名与下载

- 命名规则可使用一个 `{原模板ID}`，也可直接填固定名称；同批重名（包括仅大小写不同）自动加 v2、v3，保留其他模板主动填写的版本名。名称使用英文字母、数字、下划线或连字符，最长 180 个字符，不可与原模板名称相同；添加版本号时为后缀预留长度。
- 新 ID 写入 bytes 内部，不能只改文件名。单模板重跑可单独填写“新模板 ID”。
- 临时更改导出目录只影响本批次，不改默认设置。
- 例如 `lessTxkd090_m.bytes` 已存在，导出为 `lessTxkd090v2_m.bytes`，继续重名则 `lessTxkd090v3_m.bytes`。后缀追加在完整新 ID 后，不拆改原有 `v1` 字符。内部 TemplateId 同步更新并独立验收；后续结果、下载和同步使用最终名称，预览和完成提示均显示改名结果。
- 未修改导出命名时保留当前产物名称；生成、重跑、导出与 ZIP 都自动处理同批重名，目录导出同时避开已有文件。模板库同步仍按已有的预览、相同内容跳过和冲突备份确认规则执行，不静默修改模板库里的名称。
- 单个模板下载与“下载全部已验收模板 ZIP”保存到浏览器下载目录；“导出”写入页面指定的本地目录。
- 修改参数、命名、目标目录，或目标文件被其他程序修改后，原预览失效，需要重新预览。

### 完成检查

- 新模板文件名与内部 ID 对应。
- 输出位置正确，冲突处理符合预期。
- 已写入或已跳过结果逐项核对完成。

3. 内容相同项直接跳过；内容不同项明确选择“备份并替换”后，点击“确认同步”。
4. 核对每个模板与每个目标的实际结果，再按团队流程检查差异并提交 Git。

成功后显示“同步成功”弹窗，每个实际仓库都有打开目录按钮；双库同步可分别打开两处目录。全部内容已相同时显示“同步完成 / 目标内容已相同，无需重复写入”。弹窗不自动消失，用关闭按钮、“我知道了”或 Esc 关闭。部分失败会提示复查，实际结果仍留在页面；同步至 Tile 仓后可在项目编辑器直接验证。

打开目录仅接受本次成功交付时服务发出的凭据，不接受浏览器指定任意路径。目录被移动、删除、替换，或系统打开失败时会显示原因；导出/同步结果不被撤销，可以重试或按所列路径手动查找。凭据只在当前服务会话有效，最长24小时；不自动执行 Git。

### 必须理解：同步与回滚

同一模板写入两个库时，如果后续目录失败，会尝试回滚该模板本次已写入的内容。不同模板分别处理，所以部分回滚时，同批其他模板仍可能成功。请按行查看“已同步、已跳过、失败、已回滚”，不要仅看整批状态。

出现“需要人工处理”或“审计记录未落盘”时，保留任务编号、目标路径、日志与备份，请研发核对后再操作。只完成预览不会写模板库；正式同步会写所选目录。模板同步不修改关卡配置；配置追加使用独立的“一键配置新参数”入口。工具不自动执行 Git 或发布线上内容。

- 内容不同的旧文件已有备份。
- 项目内验收、差异检查与团队版本提交已安排。

## 一键配置新参数

默认结合真实原模板与生成记录自动识别新模板名前后缀（如 `lessT` 改为 `noT`），原模板自己的版本号保留。“模板匹配设置（可选）”紧接“原、新模板关联（可选）”下方，可指定去除的前缀和后缀，留空自动识别。出现多个候选时，在页面勾选一个或多个原模板重新计算；多个原模板可关联同一个新模板，分别计算各自关卡参数，反向关联也支持。手填关联可多行使用同一个新 ID，例如 `hr0029=custom`、`hr0030=custom`。各原关卡分别保留自己的参数梯度，新关卡 ID 须彼此不同，不能将多行配置合并成一行。

“导出与写入”可勾选“沿用原关卡 ID 前缀”：从原关卡 ID 末尾移除原模板 ID，再拼接新模板 ID。例如 `list482r1v3zm0078v2plus1` 的原模板是 `zm0078v2plus1`，则前缀是 `list482r1v3`。此选项同名自动顺延 `v2`、`v3`，保留已有行；不勾选时沿用原命名规则。原关卡名仍使用旧模板版本时，工具可识别既有 `list` 关卡前缀；自定义名称无法可靠拆分时会说明原因，不猜测截取位置。写入仍需核对预览并确认，不自动发布。

原 B 为 0、新 B 非空时，各模式统一按算出的新 A 每种图案组数 `gA` 计算：`B种类数 = max(3, ceil((新B张数 / 3) / gA) - 1)`。先计算首副本，再将种类数差值平移到后九副本，每个副本的 B 参数均不低于 3。例 `gA=2.53`、新 B 为 30 张，首副本 B 参数为 3。新 A 缺少基准或 B 少于9张、无法容纳至少三种图案时，说明具体原因，不伪造参数。原 A 为0而新增A的反向情况不自动借用B。

在“设置”填写“配置仓库 / CSV 目录”，再从左导航进入“一键配置新参数”。选择新模板来源：输入 ID（默认读取当前输出目录）、上传 `_m.bytes`，或明确选择已生成任务。无需先同步模板；文件分批上传，单个最多 32 MB。自定义命名且无法从记录关联时，可输入 `原ID=新ID`，例如 `hr0029=custom0029`。上传文件有产物记录时无需额外输入；未知文件可展开“原、新模板关联（可选）”填写关联，新 ID 使用文件内部 TemplateId，与上传文件名无关。

选好文件、输入模板ID或选择已生成任务后，直接点击“计算新参数”，不再单独确认模板；工具自动上传、解析和关联。右侧“修改路径”操作下方和输入卡底部各有一个计算按钮，执行同一操作；任意一处启动后两处同时锁定，不能重复提交。按需限制关卡范围，起始和结束都留空时匹配全部关卡位置。

唯一进度区域显示整批总体进度、实际阶段、当前文件和完成数量。总进度按阶段累计，整批结束才到100%，不因单个中间阶段完成而提前满格，不提供未经估算的剩余时间。连接中断或刷新后可恢复同次任务；未确认的配置写入锁定重新开始，恢复原计划核对实际结果，不重复追加。

结果显示选择、关卡号、原关卡 ID、原模板 ID、新模板 ID、DupPara1–10 和状态。搜索覆盖全表，支持 20/50/100 行分页；表头勾选作用于当前页，“选择全部”作用于全部可用结果或全部搜索结果，已选数量包含其他页。“新旧副本参数对比”仅列参数变化的行，旧、新参数上下对齐。

A/B 各自 Tile 数未变时，十副本参数完整保留。类型转换时，DupPara1 的该侧种类数按 `原种类数 × 新侧 Tile 数 / 原侧 Tile 数` 正值常规四舍五入；其余九副本分别应用首副本的 A/B 增减量，保留原梯度。种子与塔幸运值原字符串保留。例如 69A/39B 变为 51A/57B，首副本 `11|0|100|6` 变为 `8|0|100|9`，后续分别应用 A−3、B+3。因为种类数为整数，平均组数近似保留，不代表消耗或体验精确复刻。

新 LevelId 规则通过下拉框单选“{原关卡ID}”或“{新模板ID}”，“自定义前缀（可选）”独立填写，两种选择均拼接该前缀，留空则仅使用所选 ID。减少批次前缀默认 `lessT`、可信增加批次默认 `moreT`、普通牌增加默认 `moreB`；用户明确编辑的规则保留。“沿用原关卡 ID 前缀”勾选后优先使用原前缀拼接新模板 ID，并暂时禁用这两个控件。Des 默认保留原备注；勾选“统一备注”后填写内容，勾选且留空将写入空备注。可下载包含映射与参数对比的 XLSX，或点击“一键添加至 config_level.csv”打开预览，核对新 ID、备注与真实 diff，再“确认追加”。

2026-11-11 副本梯度补充：仅需要重算的 B 在原有同比例/新A基准及差值平移之后，以第3副本B值为基准，第4–5副本减1、第6–7减2、第8–9减3、第10减4；降到3后保持，原本更低的重算值不抬高。例第3副本 `8|0|100|4`，后七副本为 `8|0|100|3`。前3副本、A参数、种子和幸运值不因该梯度改变；B牌量未变或A/B牌量都未变时仍保留原B十副本参数。计算、报表和写入预览共用此规则。

写入只追加 `config_level.csv`，保留原关卡行与 `config_level_list.csv`，其他字段复制原配置，尤其 `RandomType`、`StrategyGroupId`、`randomSeed_groupID`。同 ID 同内容跳过，不同内容阻断；正式写入先备份，再原子追加。来源、范围、选择、LevelId 规则、Des 或 CSV 变化后需重新预览；配置路径或原 CSV 改变时需重新计算。完成弹窗可打开配置目录，页面保留备份路径。

缺失或非法副本、歧义配置、原 A 为零而新增 A、负种类数、非空侧零种类数、超过该侧三张组容量等均逐行报错；不自动夹值。原 B 为零而新增 B 按上面的专门规则处理。减少模式中未生成新文件的无塔项不可追加；清塔后保存验收通过的真实产物可关联计算，增加模式的已验收产物也可追加。匹配基于本机 CSV，需按团队流程核实线上状态；本地追加不等于 Git 提交、CMS 发布或上线。

## 增加塔：推荐、预览与微调

先输入 ID 或选择文件，再点击“去增加塔”。无塔模板可以新建塔；有塔模板可选择“新建塔”“原塔加层”或“原塔加层 + 新建塔”。原塔不能减少牌数。两种方式会保留各自本次页面参数；批次默认和单模板覆盖分别保存，采用推荐只填入当前模板，不修改其他模板。配置页模板清单的“查看原模板”可在生成前打开源阵型、编辑器网格和查看层，不会生成新模板。

数量目标四选一：

| 目标 | 填写方式 | 验收口径 |
| --- | --- | --- |
| 新增张数 | 期望新增多少张 | 取距离目标最近的真正合法结果，等距取较大值；20 通常调整为 21 |
| 最终总量倍数 | 最终总量 / 原总量 | 例如原 60 张、倍数 1.5，目标最终 90 张 |
| 最终塔占比 | 下限和上限 | 下限包含，上限严格排除；不会为凑整越过范围 |
| 逐塔最终张数 | 原塔在前、新塔在后，逗号分隔 | 每堆可不是 3 的倍数；最终总量及 A/B 各自为 3 的倍数 |

“新增堆数”默认填 0，表示自动推荐；正整数表示指定新增堆数，旧记录中的空值也兼容为自动。“新增 Tile 类型”自动按原模板多数 A/B 选择，也可明确指定 A 或 B。原 B 为0而新增B时，参数按上文新A组数基准计算且最低3；原 A 为0而新增A时仍需有效基准。

摆放区域可选上、下、左、右、内部空白中的多个，或选“自动”。“高度、方向与摆放”展开差值、比例或手动高度、紧凑/分散、塔间距、塔与主阵型间距及整体平移 X/Y。间距与平移按整数网格计，不混用两种间距。新塔默认朝上，可选朝左、朝下、朝右；原塔默认沿用原方向。

增加塔沿用原来的新增牌安全区：锚点 **X=2–14、Y=2–16**，并且2×2占位不越出模板棋盘。两侧X=1、15不能用来新建塔，也不能在这些位置的旧塔上追加新牌。原模板未改动的旧牌原样保留；平移后的牌、新增牌及修改后的塔仍需满足安全区和完整展开检查。网格上画有坐标点不表示该点可以新增牌，增加层数也不会放宽两侧限制。

在模板“单独设置”中打开“推荐、预览与微调”。修改当前模板参数会防抖试算；推荐与完整预览均来自后端。两侧使用同一 17×19 编辑器网格和比例，新增牌接在原牌序号之后，以实线标记新增、虚线标记挪动。用滑块、减/加或“全部层”同步查看两侧。图上的具体方案在“采用此方案”前不会自动成为其他模板的参数。

推荐包含实际新增 A/B、总量、最终塔占比、取整差值及整体平移。自动平移默认开启，只作为可见方案提出；核对 X/Y 后采用，正式生成再次验收。若不希望移动原阵型，关闭“空间不足时推荐整体平移”，保持 X/Y 为 0 后重新推荐。

### 自动摆放没有完成时怎么处理

增加模式一次试算最多尝试 20,000 个搜索状态或运行 4 秒，推荐多个方案合计最多运行 8 秒。这是内部防卡死保护，不是费用或策划参数。触发保护只说明本次尚未找到完整方案，不能判断模板永远没有可行摆法。

- 如果安全区内没有满足当前区域、占用和对称约束的新塔位置，工具会说明不能新建塔的原因，不会改用X=1/15等越界位置。没有原塔可加层、也没有合规新位置时，本次不生成新文件。
- 如果“原塔加层”或其他调整实际可行，失败行显示最多两个已独立验收的方案，写明具体参数旧值→新值及实际新增张数、塔堆数。点击“一键应用推荐参数”填入当前模板的重跑窗口，再“重新生成并验收”；不会自动执行、改动命名或影响其他模板。若需调整新增目标，方案也会明确列出，不悄悄改数量。
- 如果提示指定堆数不能按对称组摆放：先把“新增堆数”改为 0 自动，再打开预览核对实际堆数、张数和位置。不要为凑指定堆数破坏原阵型对称。
- 仍触发尝试上限时，可明确选择摆放区域、减少不必要的微调约束后重新预览。工具不会用未经验证的参数冒充成功推荐，也不会静默修改原模板或放宽边界。

旧任务中的失败原因按当前可理解的文案显示；旧记录没有已验证方案时，需要单独重新运行获取推荐。历史文件不会被自动删除或改写，但下载、导出和同步会重新执行当前独立验收；此前生成在X=1/15的新增塔不再能作为合格产物交付，应重新生成。

选择棋盘中的塔或下拉堆号，可修改最终张数、方向和 X/Y；点击“更新当前塔”。单塔高度修改使用完整逐塔数量，并切换手动高度。方向独立修改，不强制改变镜像塔方向。位置默认绑定镜像，也可关闭绑定提交精确坐标；服务端仍校验位置对称，不对非法位置静默放行。锁定高度后继续调整其他塔，锁定冲突会说明原因。移动支持按格按钮、棋盘方向键及吸附整数网格的拖拽；“撤销微调”“恢复打开时参数”均会重新试算。

修改时保留上次图并明确提示待验收；等待、失败、关闭、切换模板时隔离旧响应，输入保留。点击“开始生成”后通过正式独立验收才可下载、导出、同步。失败模板可单独调整增加参数重跑。新默认命名为 `moreT{原模板ID}`，设置中与减少规则分别维护；导出同名自动顺延 v2、v3，不覆盖已有文件。

增加批次的副本参数同样按 `half-up(原首副本种类数 × 新该侧牌数 / 原该侧牌数)` 计算，以首副本差值平移后九个副本。例：69A/39B → 87A/39B，`11|0|100|6` → `14|0|100|6`。种类数因取整不变时显示“参数不变”。原空侧未改变则保留原值；原 B 为0而新增B使用统一的新A组数规则，原 A 为0而新增A仍提示缺少基准。可信增加记录由服务端识别，不凭客户端声明或名称前缀放宽校验。

## 2026-10-26 修订：增加 Btile 工具与继续调整

本节记录普通牌增加的操作规则。减少/增加塔继续按各自模式处理，原 B 为0而新增B的参数统一使用上文新A组数规则；不自动改写历史产物或已追加配置。

左侧导航“增加Btile工具”位于“一键配置新参数”上方。进入后仍使用导入、配置、导出三步，默认追加18张普通B，也可选A。数量目标支持“新增张数”或“目标总 Tile 数范围”：范围含两端，原60张、目标90–99张时，自动寻找补30、33、36或39张的合法方案；实际总量在结果显示。范围内没有高于原模板且可成组的总数时明确提示。

补入位置可选最上层、最下层或上下同时补入。自动分配尽量均分上下张数并依据合法摆放调整；自定义分别填上下张数，单侧无需为3的倍数，但合计须为3的倍数，且符合新增张数或当前模板目标总数范围。批次每个模板分别依据原张数计算，不能对所有模板固定使用同一补入数量。

| 新增层数方式 | 范围与实际要求 |
| --- | --- |
| 自动 | 默认在0–3层内找合法结果，界面无需另外填写上下限 |
| 固定值 | 非负整数，实际新增层数等于所填值；内部上下限相同 |
| 范围 | 非负整数，最少值不大于最多值，实际值包含上下限 |

自动的3层为默认试算上限；固定值和范围可更高，仅受整数安全、实际几何与搜索资源约束。0层只在当前所选方向的外层补牌，不新增层，也不任意插入中间层。底部新增层仅将原非塔牌Z统一上移，明细显示实际偏移；原塔牌全部字段与StackData原样保留，避免改变游戏中的展开位置。原牌X/Y、类型、其他字段及原非塔相对层序保留。新增牌锚点仍为X=2–14、Y=2–16，完整2×2占位不越界，不与塔的完整展开区域冲突；禁止同层新增重叠和相邻层一压一全遮盖。新牌形成有效邻层压盖，按真实源对称组摆放并尽量沿用原堆叠。无法同时满足数量、层数和几何时说明原因，不自动修理原结构。

默认新模板ID为`moreB{原模板ID}`，可在导出页改命名规则；同名顺延版本，文件内部ID同步，源文件不动。所有模式已通过的结果也可“单独调整并重新运行”；仅当前模板以导入源快照和新参数重新生成，不在上次结果上累计追加，不影响同批其他模板。下载、导出与同步继续要求当前独立验收，旧产物保留审计记录。

### 普通牌产物的一键配置新参数

“一键配置新参数”可选本工具已验收任务，默认新关卡ID为`moreB{原关卡ID}`，用户明确改过的规则保留。可信`ordinary_add`产物使用增加口径：首副本按新旧牌量同比例`round-half-up`，再把首副本A/B种类数差值平移其余副本；未变侧、种子与塔幸运值保留。

2026-11-11 统一规则：原 B 为 0、新 B 非空时，各模式均以算出的新 A 每种图案组数为基准，按向上取整后减 1、最低 3 计算；十副本 B 参数都不低于 3。新 A 基准无效或 B 不足 9 张时说明具体原因。原 A 为 0 而新增 A 仍提示缺少基准。配置继续只在预览差异并确认后备份、追加，不修改旧行；模板来源仍须真实核验，不能只靠名称授予验收权限。

### 增加塔对称与帮助阅读补充

增加塔先识别原非塔阵型逐层真实成立的左右、上下及180°中心对称，只有中心对称时允许左下/右上对角双塔，不额外强制左右镜像。没有严格对称时，新增塔以源阵型外框中心组成180°对称组。旧塔与新塔位置联动使用同一真实变换，不靠某轴原坐标恰好相同推断；安全区、完整展开和所选区域限制保持。仅选底部区域时不保证能放下需要跨上下区域的中心对称组。

使用说明的独立工具章节“增加 Btile 工具”不加步骤编号；保留连续全文、目录锚点、滚动定位及全文搜索。继续复用已有字体栈、五档字号与帮助样式。

新增层数按上下两侧合计，可以在非塔下方连续增加多层。原阵型只有一层时，上下同时补入需要上下各增加至少一层。每个新增下层都须承接紧邻上层的全部牌，包括原先最底层的牌；新增上层牌也须由紧邻下一层承接，禁止悬空和相邻层一压一完全遮盖。历史普通牌产物再次下载、导出或同步时也执行当前承接验收；不符合的需重新生成，文件本身保留。
