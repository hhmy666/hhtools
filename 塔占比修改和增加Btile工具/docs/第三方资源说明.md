# 第三方资源说明

本工具运行时不加载网络资源，不依赖外部 JavaScript 框架、CSS 框架、图标库或在线字体服务。前端资源均随工具本地分发。

## Inter

- 用途：拉丁字母、数字及常见符号显示。
- 本地文件：frontend/assets/fonts/InterVariable.woff2
- 项目来源：Inter 字体项目。
- 许可证：SIL Open Font License 1.1。
- 使用方式：仅通过本地字体声明引用，不向外部字体服务发送请求。

## Source Han Sans SC

- 用途：简体中文界面文字以及 Inter 未覆盖的字符。
- 本地文件：frontend/assets/fonts/SourceHanSansSC-VF.woff2
- 项目来源：Adobe Source Han Sans / 思源黑体项目。
- 许可证：SIL Open Font License 1.1。
- 使用方式：作为 Inter Local 后的中文回退字体，随工具离线加载。

## 图标

- 用途：导航、状态、上传、帮助和操作提示。
- 本地文件：frontend/assets/icons.svg
- 说明：图标为本项目内维护的简洁线性 SVG 图形，不在运行时调用第三方图标 CDN。

## 字体栈

全工具统一使用：Inter Local + Source Han Sans SC Local + sans-serif。

数字对齐使用 OpenType 等宽数字特性，不单独切换等宽字体。若本地字体文件缺失，浏览器会回退到系统 sans-serif；这不会影响工具功能，但会影响版式一致性。

## 许可证与再分发

随工具分发字体时，应同时保留对应开源字体许可证文本或仓库中的许可证记录。SIL Open Font License 允许在遵守许可证条款的前提下使用、嵌入和再分发字体；字体本身不得单独售卖。若后续替换字体文件或引入新的第三方资源，需要在本说明中补充资源名称、用途、来源、版本和许可证。
