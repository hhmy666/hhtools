# 关卡编辑器交付规范

每次修改关卡编辑器，在最后一次改动后、交付前，从编辑器根目录运行完整浏览器验收：

```sh
node 测试/浏览器验收.mjs
```

验收使用临时模板仓库和输出目录。必须确认命令退出码为 0，才可报告浏览器验收通过。若失败，先排查并重跑；若环境阻止运行，交付时说明阻碍与未验证的内容。

验收开始和结束时都会自动检查编辑器根目录。根目录只能放 `启动关卡编辑器.command` 和文件夹。发现多余文件时，交付者须在本次任务内完成以下步骤：

1. 根据文件用途将其移入对应的子目录，例如开发规范放入「开发」，验收脚本放入「测试」，使用说明放入「文档」。
2. 搜索旧路径和文件名，修正受影响的脚本、配置和文档链接。
3. 从头运行完整浏览器验收，确认根目录和受影响的功能均通过后再交付。

保留深色模式下的表单颜色检查、光标预览与实际落牌坐标对照、仅仓库中已有同名模板时拒绝另存，以及另存后仓库出现同名文件时拒绝同步并保留双方文件的检查。
