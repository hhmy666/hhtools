# 关卡编辑器设计

这是 Tile Family 的本地模板工作台。视觉依据为全遮盖识别工具与 Tile Unity 编辑场景，各负责不同部分。

- **外壳**：复用全遮盖工具的字号、Inter 与思源黑体。标题和模板操作集中在顶栏，桌面画布与右栏按 7:3 分配宽度，右栏独立滚动。白色表面与浅蓝页面背景；主题变量集中在 `前端/assets/workbench.css`。
- **编辑画布**：复用全遮盖工具的 `editor.css`、18:20 画板、红蓝点阵、层数角标、遮盖样式、问题描边及塔的投影数学。保留该参考画布的原色。
- **编辑控件**：使用 Unity 场景里的灰白矩形按钮、长短按钮比例和操作命名；方向与升降为方形键，分组功能移除。实际 Unity 是内置 uGUI 精灵；浏览器用 CSS 重现其外观。
- **工作流**：读取或上传 → 在唯一可见的编辑画板上调整 → 直接修改模板 ID 并另存 → 一键同步。试玩按钮直接使用当前草稿，切回编辑继续工作。
- **安全**：仓库作为只读来源；另存和同步分别走两条操作。同步只在显示已另存的当前版本后提供，不覆盖、不提交。错误显示具体原因，保留草稿。
