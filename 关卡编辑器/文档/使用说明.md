# 关卡编辑器

双击根目录的「启动关卡编辑器.command」。工具只在本机浏览器运行，启动需要 Python 3.10 或以上，无需额外 Python 库。

1. 输入模板 ID 后按 Enter，或上传 Unity 模板文件。首次启动自动查找当前用户的模板仓库；找不到时保持空白。右上角「模板库路径」可选取模板仓库、输出目录和可选 WebEditor 资源目录。个人选择保存在运行数据中，不上传 Git。
2. 左键摆牌，右键删除，Alt + 方向键移动光标并按 Enter 执行。用 Q/E 切换随机 A/B，Z 撤销，Shift+Z 重做。方向键选择对应的放塔工具，W/A/S/D 选择对应的移塔工具，再点击塔。
3. 在「模板 ID」栏改成新 ID，再点「另存为新模板」。另存 ID 只允许英文字母和数字，每一种 Tile 数量须三张成组。结果写入「输出模板」，文件名与内部 ID 一致。全遮盖、悬空等是摆放提示。
4. 点「同步到模板仓库」只新增此文件；同名时拒绝，源模板与本地输出均保留。

**试玩**：选副本档位后点「一键试玩」，可填写关卡序号，使用当前草稿和该档参数，不需要先保存或同步。复现实验时，输入实际生效的 `A种类数|随机种子|塔幸运值|B种类数`，需要时导入目标组的类型池；可复制牌面与参数逐张核对。默认走本机 Unity 分支的 DupPara 配牌方式。种子组模式是可选的版本兼容功能，与本机 Unity 分支区分显示。试玩设置和本地配置导入均不写回源仓。

**复现边界**：本机 Unity 的 `GameManager.LoadLevelData` 读取已生效的关卡与副本，`LevelDupGenerator` 用 `1411242022 + DupPara.RandomSeed` 初始化发牌随机数；局内另有 `1611232022 + seed` 随机序列。工具验证了相同 A/B 输入和种子得到相同开局牌面、换种子改变牌面。没有自动获取线上分流与 DDA 结果；未捕获的无种子随机、局内动态塔换牌、付费/活动状态和特殊局流程尚不能完整重放。实验复现还要使用目标版本的模板、类型池及生效参数。

**批量编辑**：从顶栏进入，粘贴多个模板 ID 或上传多个 .bytes。每张画布独立保存草稿和撤销状态，右侧工具跟随当前选中的模板。另存与同步仍通过顶栏对当前模板逐张操作。任一画布可以直接开始试玩，再用上一关、下一关切换模板。

**通关推演**：随机点击运行设定的局数，贪心凑组、局部最优、解锁优先与高压路径各运行一条可复现路线。所有策略使用同一开局和背包规则，输出通关结果、背包峰值与点击数。

路径发现只检查当前用户常见目录中实际存在的文件夹；没有 WebEditor 时使用空白本地配置和数字图案，用户可导入自己的 CSV，不携带原始项目配置。

## 首次安装（macOS）

已有 Homebrew 时，在终端依次执行：

```zsh
brew install python@3.13
echo 'export PATH="$(brew --prefix python@3.13)/libexec/bin:$PATH"' >> ~/.zprofile
source ~/.zprofile
python3 --version
```

没有 Homebrew 时，从 [Python 官网](https://www.python.org/downloads/macos/) 下载 macOS installer 安装，然后重新打开启动器。

如果双击提示 Apple 无法验证，先点「完成」，打开「系统设置 → 隐私与安全性」，在该启动器的提示旁点「仍要打开」，再确认打开。只对你确认来自此仓库的启动器授权。保持终端窗口打开，关闭窗口会停止本地服务。

模板目录示例：`~/Projects/tileleveltemplate/Template`。WebEditor 资源目录示例：`~/Projects/tileleveltemplate/WebEditor`。这只是格式示例，不会预填到你的设置中。工具可不带项目资料启动、上传或新建模板；自己的图案目录与关卡配置需要自己选取或导入。缺少 WebEditor 时的数字图案只作编辑兜底，不能证明与当前客户端资源完全一致。

运行记录、个人目录、输出模板、模板截图不会上传。更新前关掉启动器的终端，在 SourceTree 点击「拉取」选择 `origin/main`，完成后重新双击启动器。

开发者运行单元测试：`PYTHONPATH=后端 python3 -m unittest discover -s 测试`。浏览器验收另外需要 Node.js、Playwright 与 Chrome；安装 Playwright 后在工具根目录执行 `node 测试/浏览器验收.mjs`。验收只使用合成模板，截图默认写入忽略上传的「文档/验收截图」。这些开发测试依赖不影响日常启动。
