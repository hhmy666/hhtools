# 交付复审

- **Product Design**：走查打开、读取并编辑、另存后同步、一键试玩。入口可直接按 Enter；目标文件名独立，避免把源 ID 当保存目标。同步失败会保留已导出的文件。试玩与编辑互斥显示，试完可直接返回。截图见「验收截图」。
- **Frontend Design Premium**：核对字体、版面、色彩和反馈的规则来源；全遮盖棋盘与 Unity 控件分别承担视觉标准，检查了空状态、载入、非法命名、重名、禁用同步和错误提示。
- **Build Web Apps**：内置浏览器连接超时，使用本机 Chrome 与 Playwright。使用真实模板复制件和临时仓，测试不写入实际模板仓。
- **Impeccable**：运行静态检测，另用浏览器检查首屏、对齐、密度、按钮状态和窄桌面横向溢出。画布面与控制区之间留白，背包与道具同屏。
- **产品经理复审**：高频路径不依赖配置页面；读取一次、编辑后命名、保存一次、同步一次。首次试玩无需了解实验表；只有复现特定实验时需要填写当时生效的参数。
