# 候选换皮去重与重复计算优化

## 判定规则

- 相同位置、相同同类分组，仅将所有类型整体换名：重复，不占用新候选名额。
- 位置相同，但同类分组改变：不被本规则误判为重复。后续既有体验筛选仍独立执行。
- 坐标或所属谜题单元改变：本规则不直接合并。

新增比较标识按谜题单元及坐标排序，并按首次出现顺序归一化类型名称。只用于去重，不改变原候选 ID、原始结构签名或独立导出校验。历史原始签名在比较时转换，因此旧任务续跑同样适用；不修改已经导出的模板文件。

拦截位置包括同轮候选池、跨候选槽、恢复旧任务。相同选区的类型分配阶段另记录“同类分组 + 门槛类型的对应分组”，已验证失败的等价换名不再重复求解。随机数仍按原顺序消费，不改变参数或放宽证明要求。

## 实际核查

只读扫描工具输出目录下 379 份有效导出 manifest，按源文件 SHA、方案与归一化结构比较，发现两对跨批次仅换名结果，均为早期 ui001 测试模板：

- `20260911_19/.../aipuzzleui001s4v30_manifest.json` 与 `20260911_03/.../aipuzzleui001s4v14_manifest.json`。
- `20260911_05/.../aipuzzleui001s4v16_manifest.json` 与 `20260911_12/.../aipuzzleui001s4v23_manifest.json`。

上述相对路径中的 `...` 为 `manifests`，父目录是 `输出关卡模板/验证报告与生成记录`。这是跨导出批次的历史证据，不代表当前业务批次中已经观察到相同问题。本机任务接口没有读到可用于进一步比较的候选记录，另一个服务超时，不能据此声称所有历史任务均无重复。

## 验证

- 归一化比较：整体换名相等、同类分组改变不等、旧不透明标识保持原值。
- 跨槽防御：即使模拟标识不同，纯换名仍不计为新候选。
- 求解重复计算：固定测试中，152 次预筛包含 12 次等价重复，优化后只执行 140 次。
- 原两项精准模式测试依赖塔形不变的换名候选，现改用真实不同的静态分组，继续覆盖超过初始候选池与独立验证失败后的继续搜索。

固定塔结构、同一种子、200 次尝试的前后对比：最终都保留 1 个候选，难度模拟调用从 13 次降为 2 次（包含原模板基线），耗时从 1.714 秒降为 0.279 秒。速度收益取决于重复率；本次没有测量完整业务批次的端到端提速倍数。
