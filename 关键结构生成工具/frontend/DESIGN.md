# 关键结构生成工具 · 视觉设计上下文

> 状态：正式工具的视觉基准
> 适用范围：frontend/ 内所有页面、组件与状态
> 受众：高频制作关卡的策划，以 1440–1920 px 桌面屏为主，同时保证窄屏可用

## 1. 设计立场

这是需要长时间专注的本地生产工具，不是展示型网站。视觉目标是“安静、精确、可信”：

- 80% 界面保持克制：温和白灰底色、细边框、少量阴影和稳定排版。
- 20% 关键任务区域承载识别度：导入主操作、生成/导出任务状态轨、当前候选和主按钮使用玉绿强调。
- 信息优先级高于装饰。不放与功能无关的头像、搜索、通知、运营图或大面积渐变。
- 材质感来自半透明表层、柔和投影和精确边界，不靠多色、重高光或滥用玻璃拟态。

### 标志性表达

整套工具只保留一个主要视觉签名：**玉绿任务状态轨**。它同时服务于顶部四步流程和长任务阶段，使用连续细线、节点与温和光晕建立“正在运行的专业工作台”感。其他区域保持安静，不重复堆砌这种强表达。

## 2. 颜色 Token

所有颜色由全局 CSS 变量统一管理，组件不得创建语义重复的局部颜色。

| Token | 值 | 用途 |
|---|---:|---|
| --canvas | #F4F7F4 | 应用底色 |
| --canvas-raised | #FAFBF9 | 顶部和侧边安静底色 |
| --surface | rgba(255,255,253,.90) | 常规卡片 |
| --surface-solid | #FFFEFC | 表格、弹窗等稳定表层 |
| --surface-soft | #EEF3EF | 次级区、输入态、未选中态 |
| --ink | #17211D | 标题与主数据 |
| --ink-soft | #52605A | 正文与辅助说明 |
| --muted | #7B8882 | 时间、占位、弱化元数据 |
| --line | rgba(31,61,50,.10) | 卡片和表格细分隔 |
| --line-strong | rgba(31,61,50,.18) | 选中或焦点轮廓 |
| --jade | #0B8F62 | 主操作、当前节点 |
| --jade-dark | #08714E | 主操作 hover / pressed |
| --jade-deep | #07563D | 玉绿表层上的深色文字或线 |
| --jade-soft | #E4F4EC | 完成、选中、安全提示底色 |
| --amber | #B77812 | 暂停、待处理、可恢复警告 |
| --amber-soft | #FFF3D7 | 警告背景 |
| --danger | #C64A4A | 终止、失败 |
| --danger-soft | #FFF0EF | 危险背景 |
| --info | #4777B7 | 必要的信息提示 |

结构块 C–N 的彩色是数据编码，不属于产品强调色。它们只出现在棋盘、图例、轨迹和对应数据标签内，不进入导航、按钮或大面积背景。状态不能只靠颜色表达，必须同时使用文字和图标。

## 3. 字体与排印

字体必须从工具本地资源加载，不依赖系统已安装字体或网络 CDN：

    @font-face {
      font-family: "Inter Local";
      src: url("/assets/fonts/InterVariable.woff2") format("woff2");
      font-style: normal;
      font-weight: 100 900;
      font-display: swap;
    }

    @font-face {
      font-family: "Source Han Sans SC Local";
      src: url("/assets/fonts/SourceHanSansSC-VF.woff2") format("woff2");
      font-style: normal;
      font-weight: 250 900;
      font-display: swap;
    }

    :root {
      font-family: "Inter Local", "Source Han Sans SC Local", sans-serif;
      font-variant-numeric: tabular-nums;
    }

- 英文、数字、模板 ID 和数据使用 Inter。
- 中文使用思源黑体简体中文。Inter 缺少中文字符时自动回落到思源黑体。
- 全工具只使用这一套字体栈，不为代码、时间或数字创建额外字体族；数字对齐使用 `font-variant-numeric: tabular-nums`。
- 字号严格收口为五档 Token：页面主标题 30 px、流程/详情/弹窗标题 24 px、卡片/章节标题 18 px、正文/导航/按钮/表单/表格 14 px、标签/辅助说明/状态/棋盘标注 12 px。
- 字重、颜色和间距继续表达原有层级，不通过增加 13、15、17、19 px 等相邻字号制造新的视觉角色。
- 不使用全大写长标题。英文 eyebrow 只作短小导航辅助，字距不超过 .14em。
- 数量、百分比、层数、时间、种子和参数表使用等宽数字，避免数值变化引起跳动。

本地文件：

- assets/fonts/InterVariable.woff2
- assets/fonts/SourceHanSansSC-VF.woff2
- 两款字体的许可证文件与字体资源放在同一目录。

## 4. 间距、圆角与层次

- 基础间距单位为 4 px；常用值为 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 输入与按钮高 40–44 px；主操作最小 44 px；图标按钮不小于 36 px。
- 圆角：小控件 9 px，普通卡片 14–16 px，主任务面板和对话框 20–24 px。
- 不为每个文本块再套一层卡片，避免“卡片套卡片”和强制等高。
- 小阴影：0 1px 2px rgba(16,37,30,.04), 0 8px 24px rgba(16,37,30,.035)。
- 浮层阴影：0 24px 64px rgba(20,50,40,.10), 0 4px 14px rgba(20,50,40,.05)。
- 大部分结构依赖留白和 1 px 细边框分组。阴影只用于主面板、对话框、当前候选和悬浮操作。

## 5. 布局系统

### 应用外壳

- 顶部栏 64–68 px，左侧导航 176–188 px，内容区设置合理最大宽度，避免在 1920 px 屏幕上过度拉伸。
- 侧边栏与工作区**不使用从上到下的硬分割线**。依靠轻微底色差、24–32 px 间距、导航选中态的内嵌玉绿边缘分区。
- 左侧常驻功能仅使用真实能力：创建任务、任务记录、验证报告、一键配置新参数、目标消耗校准、设置。主导航五项使用同一固定高度、图标规格和文字基线；不得因文案较长而换行或单独增高。
- 使用说明从右上角在当前页面内打开同风格说明界面，不跳转或启动外部 README。

### 页面密度

- 设置页模板仓库使用一行原生单选项切换“选择模板目录 / 手动输入路径”，共用一个路径控件。选择模式显示只读路径和“选择目录”按钮，手动模式仅显示可编辑路径；不再同时要求仓库根目录与模板子目录。沿用全局表单字号、玉绿选中态和按钮高度，窄屏选项自然换行。
- 数量下限与上限保持相同的三方式复合控件：按占比、按数量、不限制；新建下限默认按占比 0%，不限制时禁用数值输入，切换后同步单位。
- 导入页：单一核心输入卡居中，最近任务紧随其下；完成输入后再展示复杂配置。
- 配置页：左侧为批次/成品项清单，中央为当前模板与分区，右侧为与当前对象直接对应的参数。批量操作位于清单表头。原阵型使用固定紧凑预览高度并在内部完整缩放，不随模板纵横比撑高页面；右侧参数栏为复合输入保留稳定宽度。结构块最高层限制与最大层间距同一行等宽排列，复合输入的方式与数值各占一半。
- 配置页将谜题数量、候选数量等高频参数放在主表单；新建方案默认 6 个候选、位置不限、对称关闭、分布紧凑、每种类型 0 组（随机分配）、最大层间距 5。搜索预算（默认每个成品项 2,000 次）、难度目标、体验原型、特殊机制预设、线上风格参考、种子、类型白名单和质量偏好统一收入“复现与高级设置”。类型输入仅呈现“类型范围 / 确定数量”；标准组数与自定义组数向量使用互斥控件。标准组数允许填写 0，表示每类至少 1 组、在总数量上下限内按候选 Seed 随机分配。标准配置将“种类方式 / 最少 / 最多”放在同一三列行，将“每种结构块组数”独立一行，再将“结构块数量下限 / 结构块数量上限”并排，避免侧栏复合输入框被三列挤窄，不用卡片套卡片。难度目标使用三个同尺寸选项；整板体验目标使用三列紧凑选择器，不在主表单增加常规配置负担。
- 配置页标题右侧在“返回导入”左边提供“进入精准模式”。进入前保存当前统一方案和全部模板单独方案；进入后批次默认改为 3 个候选、每个成品项 20,000 次、最大层间距 5、位置不限、对称关闭、分布紧凑，其他字段保持原值；按钮与批次摘要清楚显示当前模式。精准模式只展示硬规则、难度目标、副本梯度和机制压力（低/中）均达标的候选，预算不足时允许少于目标数，不用不达标候选补位。退出时恢复进入前保存的统一方案和模板单独方案；若当前配置直接以精准模式载入、没有会话快照，则恢复普通模式默认值。
- 生成/导出进行中：不使用“大空白 + 单一 spinner”。生成任务页与候选页使用相同内容宽度；主进度卡同时显示 `已完成 / 总工作项`、百分比、当前模板、已用时、服务状态和四段任务状态轨，完成节点只显示勾选图标，不与步骤数字叠加。实时日志与任务概览使用下方两张独立等宽卡片承载，不用硬分割线拼成一张卡；继续搜索预算在主卡内使用分隔与留白建立层级，不再嵌套渐变卡片。
- 候选页：一个候选是一张完整但紧凑的卡片；桌面端首屏优先容纳候选棋盘、关键摘要和选择操作。同一成品项允许加入多个候选，选中态同时使用玉绿描边、绿勾和“已加入”文字，不只靠颜色表达；选择动作不自动跳走。成品项的上一项 / 下一项切换放在候选卡片与分组翻页之后，使阅读、选择、切换按自然任务顺序排列。
- 参数页：线上关卡索引与未上线模板索引是两个对等模式，使用同一页内分段切换，并共用一组“输入 ID / 上传文件 / 沿用刚导出模板”来源入口。未上线模式自动检索可用 `config_level`，不展示面向内部目录结构的配置集选择；重复模板 ID 使用文字徽标和行底色双重表达，不只靠颜色。
- 参数页两个索引模式沿用同一双栏宽度；未上线模式左右卡片在桌面保持同顶线同底线，左侧“查询原模板参数”占满表单可用宽度。窄屏改为单栏，无横向溢出。
- 消耗校准确认模板后定位下一步操作；前后缀匹配为两个等宽可选字段，不嵌套卡片。后台计算用分隔线下的简洁进度区展示真实模板/副本完成数、阶段与耗时；完成定位审阅表，失败保留具体原因和重试入口。自动匹配有歧义时不猜测，表头标明对应 CSV 原模板。
- CSV 上传后立即展示匹配结果；明确填写前缀时严格按剥离后的完整 ID 匹配，不回退到加工源。结果标题只展示新模板与 CSV 对应 ID，加工源放在按需查看的信息中。通用限制在审阅表顶部说明一次，逐档仅显示短状态；不能预估的数值不显示为“偏差 0%”。审阅 CSV、DupPara 草案、写入配置三个按钮同一行等宽等高，窄屏允许按钮文字换行，不拆散操作组。首副本参数输入值使用正文墨色。
- 历史数据匹配失败或有歧义时，在前后缀下方显示带警告色边线的整行提示区，使用 18 px 标题与 14 px 正文，列出全部待处理模板及原因，并提供聚焦前后缀的操作；不把问题藏在辅助小字或悬停提示里。匹配成功时使用简洁的成功状态。
- 消耗校准提供默认不勾选的“按结构块种类数自动扣减首副本上限”。勾选后读取真实替换记录中的不同结构块类型，分别从首副本源 A/B 扣减得到搜索上限，不让用户手填种类数；未勾选沿用原规则。勾选时机械扣减值保留为参考参数，受影响类型允许继续向下搜索，使用既有 A=4/B=3 经验底线，原值更低时不抬高；后续档位保留源上限并联合检查梯度。线上消耗目标出现随副本号回升时，本次目标沿用前一个有效副本目标，保留原线上值与调整来源；缺失数据不补造，手动目标不自动压低。
- 审阅表顶部区分已读取 CSV 的关卡范围与模型训练关段；跨关段正常显示数字与“跨关段预估”，训练范围不再是关卡号硬门槛。共性说明简短写明迁移待实测，以及加工源消耗暂按目标计算的假设，详细模型口径放入使用说明与导出记录，不重复塞入每个副本行。加工源参数与线上源不同时，明确各档 A/B 搜索边界与模型原参数来自加工源，线上源保留目标与原参数对照；缺少必要输入时才使用“仅模拟排序”，不把模拟参考包装成已匹配消耗。
- 详情导航分别显示成品项与候选的当前位置，跳过没有候选的成品项；跨项查看后返回恢复最初来源项、分页和焦点。长模板 ID 可换行，不靠裁切隐藏溢出。
- 参数页双栏只承载模板来源与参数输入；“新模板参数推荐”在双栏结束后使用页面全宽展示，长表格不得参与右栏宽度计算或挤压上方策略选项。
- 重做副本梯度的五张选项卡在宽屏一行等高；中间宽度以等宽的 3+2 居中重排，不留下孤卡；极窄屏改为单列。默认保真副本参数单独一组且强调原 Seed/Luck、主/次牌经验底线与“非消耗复刻”。
- “目标消耗校准”是左侧导航中的独立 Beta 工作流，与参数索引互不依赖。它复用“输入 ID / 上传文件 / 沿用刚导出模板”来源入口，从历史 CSV 的关卡号自动识别范围，不展示配置集和关卡段。两个 CSV 上传控件同一行等宽；其下四个参数控件等宽排列，策略 ID 使用与相邻控件一致的原生下拉框选择“和原关卡一致 / 1003 / 1004”。可选 `config_level.csv` 仅覆盖本次计算，未上传时使用当前 ulinkconfig。十档结果使用可水平滚动的语义表格，每个模板标题行可单独指定首副本最高参数并重算。偏差超过 25% 的档位使用琥珀色“人工确认候选”，不阻止导出或写入。写入操作必须先备份、再原子更新目标 `config_level.csv`。
- 候选详情在“候选摘要”内、基本指标上方常驻五项策略样本通过率，按随机、贪心、局部最优、解锁优先、压力测试横向五等分排列。每列仅两行：12 px 策略名、14 px 通过率，统一居中对齐与等宽数字；整体 58 px 高，使用细分隔线，不单独占用标题行、不再纵向列成五行或嵌套卡片。完整分组语义通过可访问名称保留。“样本优选”表示五项通过率合计最高，默认加入一项；并列取首项，全为 0 或缺项不推荐。人工选择与主动清空始终优先。
- 样本优选与规则、难度结论分开呈现。规则未通过的候选不参与样本优选；难度未达标或动态依据不足仍显示警告语义，导出前保留额外确认。导出记录与报告准确保留原结论，不改写为“硬校验通过”；候选身份、源文件或重写完整性异常不可绕过。
- 详情/播放页：精确棋盘保持足够辨识度但不垄断页面高度；A/B 使用浅灰绿区分，字母比结构块标签大一级且不加粗，层数标注位于牌面上部但不贴边。A/B 在分层详情中使用 80% 透明度，让下层 C–N 仍可辨识。桌面端棋盘与摘要约按 64% / 36% 分配，右侧摘要以双列指标提高信息密度，窄屏回落为单列。求解轨迹、三段背包状态和本步结算紧随棋盘，并在常见桌面窗口内保持高可见优先级。候选详情用“成品项 / 候选”两组轻量箭头与数量指示切换，加入导出与返回列表保留为等高主操作；计数同时标明本模板和全部模板的已加入数量。首尾禁用态清楚可见，返回列表保留来源分页与选择状态。右侧摘要同时给出原模板 Tile 总数、非塔 Tile 总数、总层数、非塔层数，以及当前候选结构块的最低层、最高层和层间距。
- 生成页和候选页不再重复展示“本批模板与候选”清单。候选全部补齐后直接展示候选列表与成品项切换；未补齐时保留任务信息和续跑入口，未完成项的计数旁提供“查看原模板”弹窗。暂停、失败或终止时同样可查看未完成项原模板。进入候选详情/播放或横向比较时隐藏任务进度和部分完成信息，返回候选列表后恢复；后台轮询不得打断审阅或重新显示任务卡。
- 部分候选的续跑使用一张轻量预算卡：先列出每个成品项的“已找到 / 目标数”，再显示每个成品项的当前/推荐累计上限、下一轮新增尝试、任务累计尝试、仅对应推荐档的启发式用时估计，以及“本任务搜索成功率（参考）”。卡片只保留一个“继续搜索未完成项”主操作，不在每行复制同类按钮。
- 候选卡不堆叠结构指标，只常驻三个决策信号：体验原型、与原模板难度距离、机制压力。低 / 中 / 高机制压力使用柔和语义底色；缺少路径证据时用虚线和“未评估”。机制压力未经真实玩家数据标定时，不使用“玩家风险”或“体验风险”文案。
- 候选详情通过一个“整板体验依据”展开区呈现硬校验、原型分项、难度距离、线上风格距离、机制压力、已观测风险、证据覆盖和揭露曲线。所有分项展示后端返回的实际数值或状态；旧记录缺失时显示“方向性参考 / 未评估”，不用泛化文案代替证据。
- 导出完成态优先显示成功结论、输出文件和“打开输出目录 / 创建新任务 / 一键配置新模板参数”三个等宽后续动作；同时保留进度条、四阶段轨和实时日志，便于复核实际执行过程。

## 6. 材质与图形

- 背景可使用极淡等高线或棋盘网格，不干扰文字和 Tile 边界。
- 玻璃感仅用于长任务状态中心、求解播放器和模态弹窗；必须有实色回退，不把正文直接放在高模糊背景上。
- 彩色棋盘本身是视觉焦点，外围面板保持中性。
- 图标采用 1.7–2 px 线性笔触。同一操作在所有页面使用同一图标、文案和视觉等级。

### 棋盘视图

- 棋盘采用与 Unity 关卡编辑器一致的俯视角；普通 Tile 的屏幕位置只由平面坐标决定，层数用于遮挡顺序，不做等距投影位移。
- 层数控件表达为“显示至第 N 层”：展示第 1–N 层并隐藏更高层。候选卡、详情、播放和对比视图必须使用同一口径。
- 塔必须依据模板内明确的塔数据与方向渲染，不能依赖坐标聚类猜测。
- 层数切换应保留当前缩放和视图中心，避免策划比较相邻层时产生视觉跳动。

## 7. 交互与可访问性

- 主操作为实心玉绿；普通次操作为白底边框；弱操作为 ghost；终止仅在确认弹窗中使用高强调危险样式。
- Select/Listbox 的权威实现为原生 `<select>`；本地生产工具接受操作系统管理的弹出几何与键盘交互，不自建 ARIA listbox。
- 所有可交互元素使用语义化 button、a 或表单控件，并具备 hover、pressed、disabled / busy 和可见键盘焦点。
- 使用应用自有弹窗处理终止确认，不调用浏览器 alert、confirm 或 prompt。
- 状态变化动效以 140–220 ms 为主，只用于透明度、轻微位移和状态轨。尊重 prefers-reduced-motion。
- 全局滚动条保持可见和可操作；长表格、参数面板与说明弹窗各自拥有明确滚动容器。
- 使用说明弹窗的标题、搜索、关闭按钮和分组目录固定；只有右侧正文滚动。说明按“先选任务 / 完成一次生成 / 继续与校准 / 规则与证据”组织，每章先交代目标、选择依据与完成检查，再按“必须理解 / 按需查看 / 技术口径”分层。打开时显示当前主题，并提供“第一次使用”快捷入口。
- 搜索返回命中的具体小节并高亮命中词，不用整章过滤代替结果定位；Seed、DupPara、StrategyGroupId、1003 等技术词同时支持中文别名。
- 最低可访问性目标为 WCAG 2.2 AA；必须验证文本对比、焦点、弹窗焦点管理和动态状态播报。

## 8. 响应式与布局稳定

- 大屏使用完整左导航与三栏配置；中等屏将导航压缩为图标轨；窄屏改为单列，导航收入底部或菜单。
- 数据加载、状态文案变化、按钮 busy 和滚动条出现时不得使主操作跳动。
- 棋盘有固定可用高度范围和内部缩放，不通过截断 Tile 适配。
- 候选卡和详情棋盘使用响应式高度上限，避免“大棋盘把播放器推到屏外”；在 1440–1920 px 桌面窗口中优先让候选决策信息和播放器进入首屏或一次极短滚动范围。
- 表格在窄屏优先保留列语义和水平滚动，不把 20 列参数强行挤进一屏。

## 9. 决策边界

- 本文件是持久视觉决策的权威入口；UX-CONTRACT.md 是交互与状态的权威入口。
- CSS 变量是视觉 Token 的运行时所有者。修改本文 Token 时，同一变更必须同步修改样式与视觉回归基准。
- 新页面优先复用既有外壳、按钮、状态标签、弹窗、表格和任务状态轨，不在页面内创建同功能的新样式。
- 不得用视觉文案掩盖业务边界：“硬校验通过”不等于“整关完全验证”，“暂停”不等于立即中断当前原子步骤。
