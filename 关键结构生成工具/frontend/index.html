建立模板清单

目标是得到一份可解析、可逐项配置的源模板清单。

怎么操作

  1. 已有本地仓库时粘贴一列模板 ID；只有文件时选择或拖入多个 _m.bytes。
  2. 点击“解析模板”，等待每个条目返回结果。
  3. 核对 Tile 总数、非塔层数与失败原因；移除错误项或修正来源后再继续。
两种方式都不改写源文件

模板 ID 依赖 Tile 源目录；直接上传不依赖该目录。单项失败不会清空其他成功模板。

本节名词_m.bytes：关卡模板文件；模板 ID：不带文件后缀的模板标识。

设计难度与关键结构

这一步决定生成几份成品、替换哪类 Tile，以及候选应保留怎样的难度和揭露体验。

必须理解

先选难度目标，再选体验原型

难度目标
  • 难度保真：优先贴近原模板，尽量避免 7 格背包失败路径。
  • 标准关键结构：允许少量高压路径，但必须经过策略模拟。
  • 强卡点：只在明确需要高压场景时主动选择。
体验原型
  • 内生门槛型：C–N 自身解锁承担主要难度。
  • 整板揭露型：A/B 分批露出 C–N，结构三消后释放下层。
  • 混合型：同时存在结构内门槛与整板揭露。

不确定时保留“自动判断”。置信不足会显示证据缺口，不会把诊断第一名伪装成确定结论。

建议按这个顺序配置

新建方案默认 6 个候选、最大层间距最多 5 层、每个成品项搜索上限默认 2,000 次；质量偏好默认为位置不限制、对称关闭、分布紧凑。它们是可修改的起点，不是硬规则。

  1. 确定成品关系：s5 + s6 是两份成品；s5s6 是同一模板内双谜题。
  2. 确认替换来源：按原模板 A/B Tile 实际总数判断，A≥B 时默认替换 A，否则替换 B；也可人工改为 A+B、仅 A、仅 B。
  3. 选择难度目标与体验原型，再设置结构类型、层范围、数量和塔模式。
  4. 最后设置候选数、搜索预算与 Seed；批次中的例外模板再单独调整。
可以进入生成的标准

每个成品项都有明确的结构步数、替换来源、难度目标和塔范围；默认替换来源不足时应修正配置，而不是期待工具偷偷换类。

需要更严格筛选时进入精准模式

入口位于“返回导入”左侧。进入后默认使用 3 个候选、每个成品项搜索上限 20,000 次、最大层间距 5 层、位置不限制、对称关闭、分布紧凑，其余配置保持不变；退出时恢复进入前的统一方案和单模板方案。精准生成只返回同时满足全部参数硬规则、难度目标、副本梯度安全，并且机制压力为低或中的候选；预算耗尽时结果可以少于 3 个，不会用未达标候选回填。

按需查看结构范围、Seed 与特殊预设
  • 结构种类只提供“范围”和“确定数字”，并用 C–N 白名单限制类型。
  • 标准配置把“每种结构块组数”应用到每一类，默认每种 0（随机分配）、每组固定 3 格；例如确定 3 种且每种 2 组，共生成 18 格。填写 0 时不固定每种组数，每类至少 1 组，并在结构块数量上下限内按候选种子随机分配。
  • 自定义每类组数会由填写项数确定种类数：2；1；1 为 3 种、12 格，2；2；2；1；1 为 5 种、24 格。标准配置与自定义配置二选一。
  • 双谜题的 C–N 类型互斥；组数按每个谜题单元分别应用。层间距 = 最高结构层 − 最低结构层。
  • 位置与分布会影响候选生成，对称偏好参与质量排序；这些偏好都不是难度证明。
  • 谜题 Seed（随机种子）可自动生成、复制或锁定；未锁定 Seed 只服务当次生成。
  • 全类型长程型限单谜题且非“仅塔内”，强制 C–N 12 类×3；串行机关型限 Z 向 high→low 双谜题且非“仅塔内”。
按需查看配置页说明与层限制
  • 应用方式显示在生成清单的方案说明中；配置阶段只展示原阵型与规划分区，生成后的替换布局在候选页查看。
  • 门槛前回收次数为 0 时，推荐解不安排门槛前回收，首次三消在到达 sN 门槛时发生。设置回收次数时，每个谜题单元在门槛前恰好回收指定次数，首次回收还受铺垫块数约束。
  • 标准配置每种 1 组、种类范围 3–5 时，每个谜题单元生成 3–5 种、9–15 格。
  • 结构块最大层间距是硬限制：最高层减最低层不超过配置值。例如第 1–6 层的层间距为 5。
  • 禁止塔内生成时，最高层百分比按非塔区域最高层计算，数量占比按非塔 Tile 总数计算且不超过 50%；数量上限按 3 的倍数取整。配置页只显示当前有效最高层。
本节名词sN 是结构达到门槛的步数口径；体验原型描述难度来自哪里，不等于玩家胜率。

完成一次生成 · 4

决定使用哪些候选

推荐只负责缩小选择范围；人工决定前应核对难度来源、棋盘差异和证据缺口。

怎么判断

  1. 先看体验原型、与原模板难度距离和机制压力。
  2. 打开“查看与播放”复核棋盘与轨迹；差异不直观时加入最多 3 个候选横向比较。
  3. 将可接受候选加入导出；同一成品项可以保留多个版本。
  4. 完成本项后切换下一成品项，直至清单全部处理。
不推荐不等于禁止

证据不足、高机制压力或未达目标的候选不会默认加入；查看原因并人工确认后仍可选择和导出。

按需查看非统一参数与参数快照

该候选按生成当时锁定的参数保留，后续修改不会覆盖此快照。同一成品项可包含不同续跑批次的候选；参数详情显示生成时保存的配置，种类范围、随机组数保持原设定，不把随机结果当作参数改动。

实际不同的参数置顶，用强调色和“不同”标记指出差异，当前值下标明统一方案或其他候选的对照值。相同参数续跑不会显示“非统一参数”。

技术口径推荐排序与证据边界

顺序为：硬校验 → 原型匹配 → 机制压力底线 → 与原模板难度距离 → 线上风格距离 → 布局打平。

模拟策略、7 格失败路径、首次回收、首次满包和揭露曲线是模拟参考，不是玩家胜率；缺项显示“未评估”。

完成一次生成 · 5

复核棋盘与求解证据

目标是确认结构落点、遮挡关系和完成路径与预期一致，而不是只看缩略图。

怎么看

  • 显示至第 N 层：显示第 1–N 层，隐藏更高层。
  • A/B 透明：详情棋盘中 A/B 使用 80% 透明度，便于查看被遮挡的 C–N。
  • 连续复核：使用“上一个候选”“下一个候选”按候选列表顺序切换；首尾不会循环。“返回候选列表”会回到打开详情时的列表页，并保留已选与对比状态。
  • 门槛轨迹：复现结构 sN；容量安全轨迹展示 7/8 格背包下的点击与三消结算。
  • 完成标准：结构位置、揭露先后和释放下层符合目标；已理解模拟轨迹的适用范围。
技术口径轨迹证明范围

结构门槛轨迹假设外部 A/B 已清除；仅塔内位置会实时变化，因此工具不伪造静态轨迹。整板体验应结合揭露曲线与策略仿真查看。

完成一次生成 · 6

验证并交付到本地

正式导出会按锁定配置重建候选、独立复验并回读文件；完成标志是模板与证据都已落盘。

提交前与提交后检查

  1. 确认所有成品项已有人工选择，并阅读不推荐或证据不足提示。
  2. 点击预检导出，观察重建、独立复验、审计和安全写入四个阶段。
  3. 导出完成后核对模板、导出记录、验证报告和审计记录。

提示后仍可继续

  • 数据不足或模拟估算。
  • 候选不推荐或机制压力高。
  • 用户已查看并确认。

为保护文件而停止

  • 候选身份与锁定配置不一致。
  • 源文件损坏或不可读。
  • 重写或回读失败。

多候选按选择顺序使用基础名、v2、v3……且不覆盖旧文件。进入安全写入后不能暂停或终止。

继续与校准

快速复用或重建 DupPara1–10

用于按确定规则生成十档副本参数；这是参数梯度方案，不是消耗复刻。

什么时候使用

想保留原配置走势或用固定节奏重建时使用；要拟合原关卡人均消耗时，应改用“目标消耗校准”。

  1. 输入新模板 ID、上传已导出模板，或沿用刚才导出的模板。
  2. 线上模板索引需选择关卡范围；未上线索引通过导出记录追溯原模板。
  3. 先使用默认“保真副本参数”；只有明确要重做走势时才选择五种重建方案。
  4. 核对新旧 DupPara1–10，再导出推荐 CSV。
必须理解

保真方案与五种重建梯度

方案保留什么改变什么首次降低之后间隔默认底线主要风险
保真副本参数（默认）每档自己的 Seed、Luck 与原梯度Dup1–10 分别按该档原值扣实际替换的 A/B 类型每档独立计算不重建有模板证据时采用经验底线机械扣减可能低估结构占比较小的模板
通用递减每档原 Seed、Luck仅 A/B 由调整后的 Dup1 重建A：Dup2；B：Dup3每 2 档再降 1A=4，B=3不再保留原 A/B 梯度
保持一致每档原 Seed、LuckDup2–10 的 A/B 沿用调整后的 Dup1不降低—不适用十档 A/B 没有参数降难
每个副本递减每档原 Seed、Luck仅 A/B 由调整后的 Dup1 重建A：Dup3；B：Dup4每 1 档再降 1A=4，B=3后段下降较快
每 2 个副本递减每档原 Seed、Luck仅 A/B 由调整后的 Dup1 重建A：Dup3；B：Dup4每 2 档再降 1A=4，B=3可能偏离原 A/B 梯度拐点
每 3 个副本递减每档原 Seed、Luck仅 A/B 由调整后的 Dup1 重建A：Dup3；B：Dup4每 3 档再降 1A=4，B=3后段降难可能过慢

重建梯度不会把原本已低于 A=4 / B=3 的值抬高；如有模板实测或经验底线证据，以该模板证据为准。底线不是所有模板的硬规则。

十档变化预览

假设调整后的 Dup1 为 8|0|100|6，下方只简写 A/B；实际输出会逐档保留原 Seed 与 Luck。

8/6 → 7/6 → 7/5 → 6/5 → 6/4 → 5/4 → 5/3 → 4/3 → 4/3 → 4/3
按需查看线上与未上线模板如何追溯

线上关卡模板索引：关联 config_level_list 与 config_level，在所选关卡范围查找原模板位置。

未上线模板参数索引：通过导出记录找到原模板 ID，再查询全部可用 config_level；多行命中会全部保留并标记重复。

本节名词DupPara = A 种类数 | RandomSeed | TowerLucky | B 种类数；Seed 是随机种子，Luck 是塔幸运值。
继续与校准

按原关卡消耗拟合十档参数

给定原关卡 Dup1–10 的实际消耗，为每个新模板搜索完整的十档 A/B 与 Seed；没有精确命中时也输出当前搜索空间最接近值。

开始前需要什么

  • 新模板：输入 ID、上传 _m.bytes 或沿用刚导出的模板。
  • 历史 CSV：至少包含模板 ID、副本号、DupPara、关卡号、进入人数和人均消耗。StrategyGroupId 非必需。
  • config_level.csv 可选上传，只覆盖本次计算；不上传时读取当前 ulinkconfig。

怎么操作

  1. 确认新模板与原模板对应关系。
  2. 在第一行上传历史副本 CSV；如需覆盖本次配置来源，在旁边上传 config_level.csv。
  3. 在第二行依次选择消耗目标、结构降难策略 ID、结构策略仿真和 Seed 方案。
  4. 结构降难策略 ID 从“和原关卡一致、1003、1004”下拉选择；是否把策略后的盘面纳入仿真由“结构策略仿真”单独决定。
  5. 生成后逐模板审阅十档参数、目标偏差、仿真距离和备选，再决定导出或一键写入。
必须理解

十个副本都输出，但优先保证前四档

整体拟合采用 D1=4、D2=4、D3=2、D4=2、D5–D10=1 的目标权重。D1、D2 最重要，D3、D4 次之；权重只影响“更接近”的排序，不保证上线消耗精确达成。

完整输出每个模板始终输出 DupPara1–10（含 Seed）；无法命中目标时明确标出“最接近值”、偏差与复核提示。
Seed 作用Seed 0–31 参与同参数盘面选择与风险校验；不能仅凭 Seed 判断上线消耗。“在已观测 Seed 中搜索”会让历史已观测 Seed 与原 Seed 共同参与主推荐。
结构策略选择“和原关卡一致”时逐模板读取 config_level.StrategyGroupId；选择 1003 或 1004 时，本次固定使用所选策略。
Lucky每个副本保持原值。
技术口径策略组如何进入十档仿真

每个副本都读取自己的 InstanceIdN；配置为空、0 或数量为 0 时不应用。模式 1 按配置顺序尝试并补位，模式 2 使用可复现的本地随机次序；最终生效数可能少于请求数。是否从 Dup3 开始降难由当前策略组的实际十档配置决定，不是通用规则。工具先生成该档降难后的 modifiedTemplate，再使用该档 DupPara 与 Seed 生成完整盘面并仿真。

结果怎么看

  • 上传 CSV 后自动匹配模板 ID；只有多个 ID 都可能对应时才需填写前后缀。手动填写前缀后只按剥离后的完整 ID 匹配，不再猜测其他来源。文件扩展名与导出版本号自动识别。
  • 名称冲突在开始计算前处理，修正后无需重新上传模板或 CSV。计算中若修改匹配规则，需要重新生成，不能将不同来源的结果混用。
  • 预期消耗 = 原线上副本实际消耗 × 模型估计的变化倍率。现有模型使用第 200–300 关原模板与关键结构模板的成对测试数据训练；符合现有结构条件的新关段（如 300–400、1000–1200）也可预估，不再只按关卡号拒算。新关段显示“跨关段预估”，需后续实测校验。
  • 加工源与线上源参数不同时，暂按加工源原参数消耗等于本次目标计算，这是工作假设，不是加工源实测值。搜索从加工源各档原 A/B 和原 Seed 开始，在允许的上下限内递减尝试，目标仍取线上数据或手动目标。
  • 先比较十档加权消耗偏差，再结合整盘模拟选择 Seed 和细排参数。Seed 不另乘未经验证的消耗系数。跨关段偏差 ≤25% 显示“预估接近”，其余显示“偏差较大”；均不代表已在线上验证。
  • 相似历史样本只供对照。导出的区间是训练数据的历史误差参考，不是新关段的精度保证，也不人为压窄；共性说明只在审阅表顶部显示一次。缺少目标或必要输入时才显示“暂无法预估”，保留已有结果供人工审阅。
  • 模型版本、训练关段及加工源假设随审阅 CSV 和参数草案导出，便于后续加入更多成对测试数据更新模型。可在允许范围内调整首副本并重算，不存在全局“最低 7”或“Dup1/Dup2 差值”硬规则。
写入范围

“一键写入”会先创建时间戳备份，再原子更新目标 config_level.csv；不改策略表，也不发布线上配置。

本节名词StrategyGroupId 是结构降难策略组 ID；1003 与 1004 是当前可选的固定策略，不是 Seed 组。

规则与证据

按现象排查问题

先确认状态和输入，再决定修改配置、增加预算或更换路径。

“解析模板”为什么不可点？

当前导入方式还没有有效模板 ID 或文件。如使用 ID，还需先配置 Tile 源目录。

为什么没找齐候选？

查看未完成摘要。“参数已证冲突”需调整配置；“当前预算未找到”可提高累计预算继续搜索。

“证据不足 / 不推荐”能导出吗？

可以。它们是决策提示，不是禁用。查看原因、人工确认后可继续，结论会写入导出记录和报告。

为什么提示找不到原模板或导出记录？

未上线索引和消耗校准需要导出记录建立“新模板 → 原模板”对应。请使用正式导出文件，并确认它与当前输出工作区一致。

历史 CSV 没有 StrategyGroupId 怎么办？

不影响拆解。选择“和原关卡一致”时，策略 ID 来自 config_level，不要求历史 CSV 提供。

为什么重启工具后任务不见了？

运行中任务和未导出候选只存在于当前本地服务会话。已正式导出的模板和报告仍保留在输出工作区。

消耗校准的一键写入会改什么？

只备份并更新目标 config_level.csv。它不修改策略表，不提交 Git，也不发布线上配置。

没有找到相关说明

试试搜索功能名、按钮文案或字段名，例如“Seed”、“导出”或“StrategyGroupId”。

确认本机路径

已查找本机常见项目目录。请确认源模板目录，也可以稍后配置并直接上传模板。使用参数功能时再配置 ulinkconfig。
