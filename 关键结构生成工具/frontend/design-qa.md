## 3. 实际行为证据

### 3.1 生成与任务状态

- 运行态同时显示：当前模板 / 方案、已处理工作项、百分比、有效用时、本地服务健康度和四阶段状态。
- 实时日志与任务概览为两个等权卡片；候选完成后，详细内容默认折叠。
- 暂停、继续、终止均以服务端真实状态为准；暂停时间不进入剩余时间估算。
- 固定硬规则下无候选时提供“调整此模板参数”，不会诱导用户用相同参数盲目重试。
- 动态播报只作用于精简的隐藏状态文本，不再让读屏软件反复朗读整个进度面板。

### 3.2 候选与导出

- 每个成功成品项首次出现时，仅在存在明确推荐排序时默认选择“推荐 1”；不按候选编号猜测。
- 推荐顺序按“硬校验 → 原型匹配 → 机制压力底线 → 难度距离 → 线上风格距离 → 布局打平”表达；高机制压力候选仍可查看和人工选择，但不进入优先推荐。
- 候选卡的整板体验摘要始终为三格：体验原型、与原模板难度距离、机制压力；几何与质量分数据不在卡片内叠加第四个信号。
- 候选详情依次可查看硬校验、原型、难度距离、线上风格距离、机制压力、已观测玩家风险、证据覆盖与揭露曲线，并展示每个已返回的实际分项值。
- “上一成品项 / 下一成品项”位于候选卡片与“上一组 / 下一组”之后，并显示“当前成品项 N / 总数”。
- 用户清空某成品项后会保留显式空选择；重试时只有新成功且带明确推荐的成品项补选“推荐 1”。
- 同一成品项可同时选择多个候选；实测 3 个候选同时出现绿色边框、勾选和“已选”状态。
- 导出请求携带全部选中的候选 ID；同模板同方案按选择顺序分配基础名、`v2`、`v3`，且不覆盖已有文件。

### 3.3 棋盘、比较与播放器

- 详细棋盘采用俯视分层；选择第 N 层时仅显示第 1 至 N 层。
- 详细页 A / B Tile 的实测 `fill-opacity` 为 `0.2`（80% 透明），C–N 结构块为 `1`。
- 横向比较棋盘实测高度为 220px；决策表在当前 720px 高视口内已进入首屏，在 900px 高视口可直接查看主要字段。
- 求解轨迹逐步显示：点击 Tile 与层数、结算前背包、插入后背包、三消结算后背包、消除结果和谜题门槛。
- 背包容量固定，不会因 s8 / s9 步骤数量产生槽位跳动；塔内模式不沿用普通谜题轨迹。

### 3.4 配置与文案

- 替换来源默认“原模板 A/B 数量较多者（相同选 A）”。
- 整板体验原型、特殊预设和线上风格参考都收在“复现与高级设置”；默认值分别为“自动判断”、“不使用特殊预设”和“线上 200–300 关参考”。
- 生成清单显示“Tile 总数”和“非塔层数”。
- 重做副本梯度方案顺序为：通用递减、保持一致、每个副本递减、每 2 个副本递减、每 3 个副本递减；默认方案仍是上方独立的“保真原副本参数”。
- 策略说明、候选指标、操作按钮和关键配置标签的最终计算字号均不低于 12px；时间戳等真正次要元信息允许保持 11px。
- 使用说明明确：页面可以离开，但关闭启动窗口或重启本地服务后，未完成任务与当前会话记录不会恢复；正式导出文件仍保留。
- “线上关卡模板索引”沿用 config_level_list + config_level 联查和 DupPara 推荐；“未上线模板参数索引”与它共用输入 ID、上传文件和最近导出三种来源，并先从 manifest 解析原模板 ID。
- 未上线索引自动遍历所有可用 config_level，不显示配置集选择，也不要求 config_level_list。它会保留同一原 TemplateId 的全部匹配行；每行显示 LevelId、配置来源和 DupPara1–10，重复 ID 同时使用浅琥珀底色与“重复 ID · 共 N 条”文字标识。
- 参数模式采用标准 tab / tabpanel 关系；实测 ArrowLeft、ArrowRight、Home、End 可改变选中项、焦点和可见面板。模式切换会使旧请求失效，避免隐藏页面的迟到响应覆盖当前状态。
